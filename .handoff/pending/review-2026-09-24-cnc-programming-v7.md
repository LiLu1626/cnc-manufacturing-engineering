`(0,0) → (0,50) → (50,50) → (50,0) → (0,0)`。

在正半径补偿 5 mm 的假设下，直线中段的 G41 刀具中心依次位于 X=-5、Y=55、X=55、Y=-5，均在实体外侧。边名注释已与路径一致。此结论是几何推导，依据 [Haas G41/G42 说明](https://www.haascnc.com/service/online-operator-s-manuals/mill-operator-s-manual/mill---g-codes.html)。

## 2. 剩余可定位问题

### A01 / P2：完整纠错程序仍依赖未声明的装刀与入口状态

位置：`docs/cnc-programming/39-exercises-assessment/index.html:59–64`。

Assumptions 只说明“10 mm end mill”及 H01 设置，没有明确该刀已装入主轴，代码也没有换刀；初始位置和第一段 Z 运动的净空仍未声明。把 G43 放在 XY 之前有帮助，但不能因此推断从任意初始位置到 Z50 都安全。

首次带 Z 的 `G43 H01 Z50` 未显式写运动方式。教学完整程序应明确该段意图，不让读者依赖隐含模式。D05 存 5.0 mm radius 也应落实为 Haas 偏置设置前提：Setting 40 决定偏置值按半径还是直径解释，不能只凭注释确认实际解释方式。[Haas 刀补与 Setting 40](https://www.haascnc.com/service/online-operator-s-manuals/mill-operator-s-manual/mill---g-codes.html)。

修复与验收：明确“指定刀具已经装好、G54/H01 已确认、当前位置允许安全 Z 运动、Z50 高于相关夹具、Setting 40 为半径且有效补偿为 5 mm”等入口条件，或提供相应完整流程；显式建立首段运动方式。逐段列出初始 Z、Z50、外部起点、下刀、补偿建立和取消状态。无需声称适合任意机器初始状态。

### A02 / P2：螺纹公差等级和最终验收被写成无条件规则

位置：`docs/cnc-programming/22-lathe-threading/index.html:51`。

现在写“For an external thread, tolerance class is 6g”“For an internal thread, class is 6H”，没有限定为本例选择。6g/6H 应作为明确选定的配合示例，不能教成所有内外螺纹的固定等级。完整螺纹标注及验收应以图纸要求为准。

新增“The 8.16 mm is a starting diameter — final acceptance depends on the gauge”又把理论小径、程序终点与检验混在一起。8.16 在下方 G76 中仍是最终 X 终点；若表达“初始估算值”，应明确说明，而不是称为容易被理解成毛坯/起刀直径的 starting diameter。螺纹环/塞规用于功能性螺纹检验，不能用一句“看量规”替代图纸要求的各项尺寸与检验方法。[Vermont Gage 对螺纹量规检验对象的说明](https://www.vermontgage.com/gaging-products/thread-gages)。

修复与验收：明确本例选用的完整外螺纹标注，内螺纹另作对照；将 8.16 标为理论小径估算及示例 X 终点；列清功能通止检验与需要单独确认的尺寸要求。不要承诺通过一个量规即证明全部图纸要求合格。

W07/Y02 的具体来源缺口仍在：本轮没有增加支持 0.613 系数的可定位标准条款/厂商图表，也未补牙型图，不能因量规术语改好就关闭该项。

### A03 / P3：练习答案把上一版修正错误误写成原题错误

位置：`docs/cnc-programming/39-exercises-assessment/index.html:50–58`。

答案说“original path goes counter-clockwise”，但当前原题只有 X0Y0 → X50Y0 → X80Y30，并不是上一版那个逆时针闭合方形轮廓。读者无法从题面重现答案的判断。

修复与验收：要么把题面明确换成要诊断的完整逆时针方形案例，要么删除这段对上一版程序的叙述，围绕当前题面的补偿建立、材料边界、退出和缺少 G40 解释。确保每项错误都能在题面定位；不要让修订历史进入学习答案。
