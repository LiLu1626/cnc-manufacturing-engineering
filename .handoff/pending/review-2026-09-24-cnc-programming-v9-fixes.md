## 3. 批次A：先消除剩余错误

### A1 / P1：完整修复15页圆弧，不要只替换G02/G03字样

文件：`docs/cnc-programming/15-circular-interpolation/index.html`，重点约44–48、59、67行。

1. 统一坐标前提：G17，从+Z看XY平面；起点S=(0,0)，圆心C=(25,0)，终点E=(50,0)，半径25。
2. G02是顺时针：角度180°→90°→0°，中点为(25,+25)，走**上半圆**。将当前“(25,-25)、lower”全部改正。
3. G03是逆时针：角度180°→270°→360°，中点为(25,-25)，走**下半圆**。将当前“(25,+25)、upper”全部改正。
4. 两个代码块必须标成互斥示例，各自以S=(0,0)为已明确的起点。不能将当前两行作为连续加工代码：第一行完成后起点已经变成(50,0)，第二行I25 J0会得到不同圆心。教学片段分别写 `G17 G02 X50. Y0. I25. J0.` 与 `G17 G03 X50. Y0. I25. J0.`，分别声明G90、单位、已定位起点及切削高度等前提；如果给完整定位代码，先说明净空与进刀。
5. 短弧例S=(0,0)、C=(0,20)、E=(20,20)的G03、90°判断保留。公式改为 `L = 2πr×θ/360 = 2π×20×90/360 = 31.416 mm`。原式少了2，不能保留错误等式。
6. 删除“对径起终点需要加short arc区分”的解释。对径两条弧均为180°，应区分顺/逆时针或上/下半圆；只有非对径例才讨论短弧/长弧。
7. 同步修正完成报告中G02下半圆、G03上半圆的错误总结。
8. 增加两幅SVG：第一幅同起终点的上下半圆，箭头标G02/G03；第二幅90°短弧，标半径、圆心和弧长。图、正文、代码注释及答案必须一致。

验收：用 `x=Cx+r cosθ, y=Cy+r sinθ` 独立代入90°/270°；半圆均为78.540mm，90°例为31.416mm；两个独立示例起点一致，无连续执行歧义。

### A2 / P2：修正29页与22页解释，限定控制器语境

文件一：`docs/cnc-programming/29-subprograms/index.html`，约76行Common Mistakes。

当前说G80是为了避免主程序下一条G00被解释成钻孔。Haas显式G00本身也会取消循环，不能继续教错。直接替换为：

> Cancel the cycle with G80 before M99 to make the exit state explicit. On Haas, an explicit G00 also cancels the cycle; an XY block without a cancelling motion command could repeat it.

依据：[Haas G80取消固定循环](https://www.haascnc.com/service/codes-settings.type=gcode.machine=mill.value=G80.html)。保留本轮已修好的绝对坐标主程序和独立O2000，不重新引入G91。

文件二：`docs/cnc-programming/22-threading/index.html`，约33、42、83行。

将“RPM变化必然导致编码器各刀不同步”“任何情况下always G97 never G96”的解释替换为有边界的教学选择：

> This Haas teaching example uses G97 S500 to keep spindle speed constant, following the manufacturer's G76 example. F specifies lead per revolution. The programmed lead does not change merely because RPM changes; synchronization, permitted modes and overrides must follow the specific controller manual.

Common Mistakes对应替换为：

> Using a spindle mode not verified for this threading cycle — follow the chosen controller's documented setup; this example uses G97.

依据：[Haas G76参数及G97 S500示例](https://www.haascnc.com/service/codes-settings.type=gcode.machine=lathe.value=G76.html)。该文档支持使用该教学例，不能据此推出所有控制器上RPM变化必然失同步。

删除42行把UN、梯形、锯齿形等一概说成具有不同截短关系的括号概括。保留0.61343用于本文选定的ISO公制外螺纹基本牙型的范围说明及已补来源；其他牙型应各自引用对应标准或刀具资料，不通过无来源概括扩展结论。

验收：22页正文、错误列表和答案中不再出现上述无依据的绝对断言；29页与Haas G80说明一致。
