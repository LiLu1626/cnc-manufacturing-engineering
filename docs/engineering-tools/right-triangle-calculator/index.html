Formula and use

Pythagorean theorem: c² = a² + b²

sin(A) = a/c,  cos(A) = b/c,  tan(A) = a/b

Enter any two known values (two sides, or one side + one angle) and the calculator solves the rest. Angle B = 90° − A. Angle C = 90°.

Common shop uses: chamfer dimensions, dovetail angle calculations, V-block setups, and converting between horizontal/vertical cuts and angle.

Note:

Leave unknown fields blank. The tool needs exactly two known values to solve. If you enter more than two, it uses the first two filled fields in order (a, b, c, angle A). Results are rounded to 3 decimals for sides and 2 decimals for angles.
