Unit Conversion

Engineering Utility · Released
Convert frequently used CNC and manufacturing units. Results update immediately.

Converted result
—
Use boundary: This tool converts units only. It does not establish an approved cutting condition, tolerance, machine setting, or process parameter. Confirm the drawing, control convention, machine documentation, supplier data, and approved process plan before production use.

Practical CNC Reference

  • 1 in = 25.4 mm — common for drawing dimensions, tools, and stock allowance.
  • 1 sfm = 0.3048 m/min — useful when comparing metric and imperial tooling data.
  • 1 ipm = 25.4 mm/min — verify whether the program uses feed per minute or feed per revolution.

How to Use

  1. Choose the physical quantity.
  2. Enter the known value and select its source and target units.
  3. Confirm the result against the drawing, control, catalog, or inspection plan.
