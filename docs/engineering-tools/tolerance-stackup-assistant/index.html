Stack-up methods

Worst-case: total tolerance = sum of all individual tolerances. Assumes every dimension is at its extreme simultaneously. Safe but conservative — can require very tight individual tolerances.

RSS (Root Sum Square): total tolerance = √(Σ tol²). Statistically realistic assuming normal distributions and ~Cpk 1.33. Allows looser individual tolerances, lower cost.

Rule of thumb: if the assembled gap is critical (seal, bearing fit), use worst-case. If it's a cosmetic or non-critical gap, RSS is fine. Always draw the dimension chain and identify which dimensions stack up in the same direction.

Example: Three dimensions: 25±0.1, 10±0.05, 15±0.1. Worst-case total = ±0.25 (range 50±0.25). RSS total = √(0.1² + 0.05² + 0.1²) = √0.0225 = ±0.15. The RSS allows 40% more tolerance on each dimension for the same assembly outcome.
