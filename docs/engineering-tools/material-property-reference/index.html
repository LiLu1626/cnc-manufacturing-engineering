Material Property Reference

Common workpiece materials for CNC machining: recommended cutting speeds, feed guidance, and chip characteristics. Always confirm with your tool supplier for specific grades and coatings.

Reading this table

Vc ranges are starting points. Actual cutting speed depends on tool coating (TiN, TiCN, Al2O3, CVD/DVD), tool geometry, machine rigidity, and coolant. Always start at the lower end and increase.

Feed per tooth (fz) ranges. For finishing, use the lower end (0.03–0.08 mm). For roughing, use higher (0.10–0.25 mm). Stainless and titanium need consistent feed to avoid work hardening — never rub.

Coolant strategy: aluminum benefits from flood to prevent built-up edge. Stainless needs high flow to flush chips and cool the cutting edge. Titanium needs high-pressure through-spindle coolant to break the heat zone.

Safety note: these values are typical starting points for carbide tools. Ceramic and CBN tools can run 2–5× faster on hard materials. HSS tools run at 1/3 to 1/2 the carbide speed. Always refer to your insert manufacturer's catalog for exact recommendations.
