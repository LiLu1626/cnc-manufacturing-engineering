What is Constant Surface Speed?

In conventional turning (G97), RPM is fixed. When you face a part from OD to center, the cutting diameter shrinks — so the surface speed drops, and you end up cutting very slowly near the center.

Constant Surface Speed (G96 on Fanuc) automatically increases RPM as the tool moves to smaller diameters, holding Vc constant. But the spindle has a maximum RPM limit — once the ideal RPM exceeds G50 S____, the machine caps RPM and the surface speed drops.

  • G96 S200 — CSS mode, target Vc = 200 m/min
  • G50 S3000 — cap RPM at 3000 (always set this when using G96!)
  • G97 S1500 — return to fixed RPM mode

The diameter where RPM hits the cap is called the "CSS crossover diameter." Below that diameter, you're cutting at lower-than-ideal surface speed. This is normal and unavoidable — it's why the G50 limit matters.

Why this matters:

Without a G50 RPM limit, a small diameter could command 10,000+ RPM, which the spindle cannot reach. The controller will either alarm or automatically reduce RPM — but your surface speed will drop, potentially causing poor finish. Always set G50 to the machine's rated max RPM when programming with G96.
