Formula Library

All CNC machining formulas in one place. Search or browse by category. Each formula links to its calculator tool. Bookmark this page for quick reference on the shop floor.

How to use this page

Type a keyword to filter. Each card shows the formula in plain language. Click the tool name to open the calculator. All formulas use:

  • D = diameter (mm), R = radius (mm), L = length (mm)
  • Vc = cutting speed (m/min), f = feed (mm/rev or mm/tooth)
  • P = pitch (mm), θ = angle (degrees)
  • RPM = spindle speed, π ≈ 3.14159
