Threading formulas (60° metric)

Feed per revolution = pitch P. On Fanuc G92/G76, the feed is programmed as F = P (mm/rev). The spindle must be synchronized so every revolution advances exactly one pitch.

  • RPM = 1000 × Vc / (π × D) — threading uses lower Vc (30–80 m/min) than turning
  • Thread depth (external) = 0.6134 × P (H/2 height of 60° triangle)
  • Minor diameter (external) = D − 2 × depth = D − 1.2268 × P
  • For internal threads, the tap drill size ≈ D − P (60% thread engagement)

Pass schedule: Threads are cut in multiple passes with decreasing depth. Typical first pass 0.3–0.5 mm, last pass 0.05 mm. Rough guides for carbide: P=1.0 → 3–4 passes; P=1.5 → 4–6; P=2.0 → 6–8; P=3.0 → 10–12. Always check the tool manufacturer's recommended infeed pattern (compound vs. radial).

Approach distance: Leave at least 2–3 mm of lead-in before the thread start (G76 Q value). This lets the spindle synchronize before cutting the full pitch.

Safety:

Never use high RPM for threading — the feed is fixed by pitch, so high RPM means high feed rate and tool damage. Always dry-run the threading cycle without cutting first. The infeed angle (compound slide) should be 29° for external 60° threads to reduce cutting forces. Verify the final thread with a go/no-go gauge.
