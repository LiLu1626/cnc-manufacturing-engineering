Datum Planning Worksheet

Plan locating surfaces and inspection datums before setup. Good datum strategy eliminates stacking errors and ensures the part is inspected the same way it's machined.

Setup checklist

The 3-2-1 locating principle

3 points on the primary datum plane restrict 3 degrees of freedom (rotation about X and Y, and Z translation). The part rests flat on this surface.

2 points on the secondary datum restrict 2 more (rotation about Z and Y translation). This is typically an edge or pin.

1 point on the tertiary datum restricts the last (X translation). This locks the part in position.

Golden rule: machine the datum surfaces first, then use them to locate everything else. Never locate from a rough surface if a finished datum is available. The inspection drawing datums must match the setup datums.

Example: A rectangular plate. Primary datum = bottom face (3 points on the mill table). Secondary datum = left finished edge (2 points against a stop). Tertiary = one corner or a dowel pin. All milling is done from these surfaces. CMM inspection uses the same three datums, so measured dimensions match drawing dimensions exactly.
