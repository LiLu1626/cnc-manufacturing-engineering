Cutting speed
—

Formula and learning path

Cutting speed (m/min) = π × Tool diameter (mm) × RPM ÷ 1,000

Use this tool to check the actual cutting speed produced by a chosen RPM. Then use the Spindle Speed Calculator to reverse the calculation from a target cutting speed.

For beginners: A cutting speed is not a universal setting. Start from tooling supplier recommendations, then adjust for workpiece material, coolant, rigidity, engagement, and machine capability.
