Formula and interpretation

Chip load (mm/tooth) = Feed rate ÷ (RPM × active cutting edges)

Chip load is the programmed feed movement assigned to each active cutting edge. It is a starting value, not a guaranteed chip thickness under every engagement condition.

For beginners: Too little feed per tooth can cause rubbing; too much can overload the cutter or machine. Start with the toolmaker's material-specific range and reduce conservatively when rigidity is limited.
