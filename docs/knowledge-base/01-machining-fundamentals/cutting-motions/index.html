01.3 · Machining Fundamentals

Cutting Motions

Every machining operation is produced by the relative motion between the tool and the workpiece. There are two fundamental motions — cutting motion and feed motion — and they combine to produce the desired geometry.

Cutting Motion (Primary Motion)

This is the main motion that generates the cutting speed Vc. It is usually rotational (the spindle spins the tool or workpiece):

  • Milling: the spindle rotates the end mill.
  • Turning: the spindle rotates the workpiece; the tool moves linearly.
  • Drilling: the drill rotates and feeds axially into the part.

Cutting speed Vc is measured in m/min (surface feet per minute, SFM, in imperial). It is the speed at which the tool edge passes across the workpiece surface.

Feed Motion

Feed motion moves the tool (or workpiece) so that a fresh cutting edge engages new material. It is usually linear and perpendicular to the cutting motion:

  • Turning: the tool feeds along the workpiece axis (longitudinal feed) or across it (facing/cross feed).
  • Milling: the table moves the workpiece past the rotating cutter.
  • Drilling: the drill feeds axially into the hole.

Depth of Cut

Depth of cut (ap in turning, ae in milling) is how deep the tool penetrates below the machined surface. It is set once per pass and is not the same as feed.

Rotational vs Linear Motion

In milling, the tool rotates and the workpiece feeds linearly. In turning, the workpiece rotates and the tool feeds linearly. In both cases, the chip is formed by the same shear mechanism — only the kinematics differ.

Key distinction: cutting speed determines tool life and heat. Feed determines surface finish and chip load. Depth of cut determines how much material you remove per pass. These three are the "cutting conditions" — set them and the machine does the rest.
