Core Machining Formulas

Spindle Speed from Cutting Speed

RPM = (1000 × vc) / (π × D)

vc = cutting speed (m/min), D = tool diameter (mm)

Imperial: RPM = (12 × SFM) / (π × D)

Calculate it →

Feed Rate

vf = fz × z × RPM

vf = feed rate (mm/min), fz = feed per tooth (mm), z = number of flutes

Chip load reference →

Material Removal Rate (MRR)

Milling: MRR = ap × ae × vf (mm³/min)

Turning: MRR = ap × f × vc (mm³/min, f = feed per rev)

Drilling: MRR = π/4 × D² × vf

MRR explained →

Cutting Time

t = L / vf

L = total tool travel length (mm), vf = feed rate (mm/min)

Tool Life (Taylor Equation)

V × Tn = C

V = cutting speed, T = tool life (min), n and C = material constants

Trigonometry Quick Reference

Every machinist needs basic trig for angles, tapers, and bolt circles.

FunctionFormulaUsed for
Sinesin(θ) = opposite / hypotenuseAngles, taper, chord calculations
Cosinecos(θ) = adjacent / hypotenuseHorizontal/vertical components
Tangenttan(θ) = opposite / adjacentSetover, taper per side
Pythagoreanc = √(a² + b²)Diagonal distances, bolt circle coordinates

Example: taper angle. A part tapers from 30 mm to 20 mm over 50 mm length. The angle per side is:

tan(θ) = ((30 − 20)/2) / 50 = 5 / 50 = 0.1

θ = arctan(0.1) = 5.71°
