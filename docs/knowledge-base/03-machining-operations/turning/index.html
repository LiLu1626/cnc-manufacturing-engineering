03.1 · Machining Operations

Turning Operations

Turning is machining on a lathe: the workpiece rotates, and a single-point cutting tool moves linearly to create cylindrical shapes. It is the most efficient way to make round parts — shafts, bushings, pulleys, threads.

How Turning Works

Basic Turning Operations

Facing

The tool feeds perpendicular to the workpiece axis, creating a flat surface on the end. Done first to establish a flat reference surface.

OD Turning (External Turning)

The tool feeds along the workpiece axis, reducing the diameter. This is the most common turning operation — roughing down to size, then finishing.

ID Turning / Boring

The tool reaches inside a hole and feeds along the axis, enlarging or finishing the inside diameter. Boring bars have overhang, so they are prone to chatter — see Boring-Bar Deflection Check.

Grooving / Parting

A narrow tool feeds radially into the part to cut a groove (for O-rings, retaining rings) or to cut the part off (parting). Grooving tools are very narrow and fragile — see Grooving Parameter Assistant.

Threading

The tool feeds at exactly the pitch (lead) per revolution, creating V-shaped threads. Done in multiple passes. See Threading Calculator.

Taper Turning

The tool feeds at an angle to create a tapered surface. Calculated with Taper & Angle Calculator.

Chamfering

A small 45° cut at the edge to remove sharp burrs. Usually programmed as a short linear move.
