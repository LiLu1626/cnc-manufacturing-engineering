12.1 · Machine Troubleshooting

Machine Troubleshooting Guide

When a machine acts up, don't start replacing parts. Work the problem systematically: observe the symptom, list possible causes, check the easy things first, then dig deeper.

Structured Method

Symptom → What exactly is happening?
Possible Causes → What could cause this?
Diagnostic Checks → What can I measure?
Corrective Action → What fixes it?
Prevention → How do we stop it recurring?

Common Problems

SymptomCommon causesFirst check
Poor surface finish / chatterTool wear, deflection, loose fixturing, spindle bearingIs the tool sharp? Is the part rigid?
Dimensional driftThermal growth, worn ballscrew, lube issueDid the machine warm up? Check after 30 min.
Alarm on axis moveOvertravel, servo fault, encoder errorRead the alarm code — don't just reset
Tool changer failureAir pressure low, misaligned pot, jammed chipAir pressure? Any chip in the drum?
Chuck not holdingClamp pressure low, worn jaws, hydraulic leakGauge the chuck pressure

Start with the obvious. 80% of "machine problems" are low air pressure, empty lube tank, a chip jam, or a dull tool. Check these before calling a technician. Read the alarm code — controllers tell you exactly what's wrong if you look.
