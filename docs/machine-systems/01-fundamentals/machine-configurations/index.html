01.2 · Machine Tool Fundamentals

Machine Configurations

How a machine is built determines what it's good at. Vertical vs horizontal, 3-axis vs 5-axis, rotating workpiece vs rotating tool — these are the fundamental configuration choices.

Vertical vs Horizontal

VerticalHorizontal
Spindle orientationVertical (down)Horizontal (sideways)
Typical machinesVMC, VTL, vertical millHMC, horizontal lathe
Chip evacuationChips fall onto part/tableChips fall away from work
Gravity effectFixturing supports part downwardPart weight on chuck face
Best forPlates, molds, boxy parts, one-sided workProduction, prismatic parts, multi-side machining

Rotating Workpiece vs Rotating Tool

This is the most basic split between machine types:

  • Rotating workpiece (lathes): The part spins in the spindle; the tool moves linearly. Good for cylindrical parts — shafts, disks, bushings, rings.
  • Rotating tool (mills): The tool spins; the part stays on the table. Good for prismatic parts — blocks, plates, housings, molds.
  • Both (turn-mill, mill-turn): Part indexes while tool cuts. Combines both operations in one setup.

Axis Configurations

3-Axis

X, Y, Z move simultaneously. Tool approaches from one direction (usually vertical on a VMC). Good for: pockets, faces, holes drilled from top, simple profiles.

4-Axis

Adds a rotary axis (A or C). Part rotates so you can machine sides without re-fixturing. Good for: round parts with flats, cams, manifolds, parts needing holes on multiple faces.

5-Axis

Two rotary axes (A+B or A+C). Tool tilts relative to the part. Good for: impellers, turbine blades, complex molds, aerospace parts — anything needing access to multiple angles in one setup.

5-axis isn't automatically better. It's more expensive, needs more programming, and for simple prismatic parts a 3-axis VMC is faster and more accurate. Use 5-axis when you need (1) complex geometry, (2) fewer setups, or (3) long-reach tool access that short tools can't achieve.
