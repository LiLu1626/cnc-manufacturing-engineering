Reconditioning & Sustainability

Solid end mills and drills can be reground and recoated; carbide scrap is recyclable. Whether reconditioning pays off depends on tool value, number of regrinds and the geometry you lose each time.

Level: BPrerequisite: 29 Tooling EconomicsScope: classroom overview
After this lesson, you can:
  • Describe regrinding, recoating and carbide recycling
  • Judge when reconditioning is worth it

Concept

Regrinding re-sharpens a worn solid carbide tool; recoating applies a fresh coat after regrind. Carbide recycling returns worn inserts and scrap to the material stream. Reconditioning makes sense for expensive solid tools, not for cheap disposable inserts.

Why It Matters

A costly solid end mill can give several more regrinds at a fraction of a new tool's cost — but each regrind removes material and changes geometry, so there is a limit. Throwing away carbide is both waste and missed recycling value.

How It Works

Send solid tools to a re-grinder that re-establishes the edge and recovers the geometry, then recoat. Track how many regrinds a tool has had; once the core/geometry is too reduced, retire it. Collect carbide scrap for recycling rather than binning it.

Worked Example

An expensive solid carbide end mill wears after heavy use. Re-grinding and re-coating costs a fraction of a new tool, and the tool returns to service. After several regrinds, though, the reduced core and altered geometry mean it is time to retire — not keep re-grinding into failure.

A simple decision rule: compare regrind cost against replacement price and the remaining geometry margin. If a new Ø10 solid end mill costs far more than one re-grind, and the tool still has enough core diameter left, regrind. Track each tool's regrind count; after the edge or core is ground below the maker's minimum, retire it. Separately, collect carbide inserts, drills and bored-out bodies in a scrap bin rather than throwing them away — tungsten carbide is a high-value recyclable material, and the return partially offsets tool cost.

Environmental angle

Carbide production is energy-intensive, so reusing and recycling also reduces waste beyond the direct savings. The same logic applies to coolant: extending tool life reduces coolant consumed per part, and dry/MQL strategies (page 23) cut fluid use. Sustainability and cost usually point the same direction here — run the right tool at the right parameters so it lasts, rather than consuming extras.

Common Mistakes

  • Re-grinding cheap disposable tools. Not worth it. Fix: recondition expensive solid tools only.
  • Re-grinding past the geometry limit. Fix: track regrind count and retire on time.

Practice

Q1. Which tools are worth re-grinding?

Expensive solid carbide tools, where regrind cost is a fraction of replacement.
