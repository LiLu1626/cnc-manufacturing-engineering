Glossary & Reference

The quick-reference page: the terms and formulas used across this course, with the locked numeric examples for fast recall.

Level: BUse: look-up, not a tutorial

Concept

This page consolidates definitions and formulas. It is a reference: use it while working, not as a first read.

Why It Matters

A single place to confirm "what does fz mean" or "what is n again" keeps decisions consistent and prevents unit errors on the shop floor.

Worked Example

Looking up "feed per tooth": fz is mm removed per flute; multiply by speed and flute count to get vf. The table gives the locked worked number so you can sanity-check your own calc.

Work the chain end to end. A Ø12 end mill at vc 150 m/min runs at n = 1000·150 /(π·12) = 3979 rpm. With 4 flutes at fz 0.05, vf = 3979·4·0.05 = 796 mm/min. If the machined surface measures 1.1 µm against a target 0.8, feed is too high for the nose radius: lower f or use a larger rε, using Ra = f²/(32·rε). Notice each quantity carries its unit through the chain — mixing mm/rev with mm/tooth is the most common arithmetic error on the shop floor.

Common Mistakes

  • Mixing mm/rev and mm/tooth. Fix: confirm the feed unit before using a formula.
  • Forgetting units. Fix: always carry units through.
