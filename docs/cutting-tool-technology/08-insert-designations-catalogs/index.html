Insert Designations & Catalogs

An insert code like CNMG 12 04 08 has a defined meaning: shape, clearance, tolerance, chipbreaker, size and nose radius. Once you can read the first few characters, a catalog stops looking like noise and becomes a selection tool.

Level: BPrerequisite: 07 End-Mill GeometryScope: metric; classroom examples
After this lesson, you can:
  • Decode the main fields of an ISO turning insert code
  • Read shape, clearance, size and nose radius from a real example
  • Use a catalog to narrow a candidate insert for a job

Concept

The ISO turning-insert designation is a coded string. Reading left to right, the first characters tell you the most: shape, clearance angle, tolerance, chipbreaker/clamp type, then size (inscribed circle), thickness and nose radius. A worked example makes it concrete.

Why It Matters

You order an insert by this code, and the holder pocket only accepts certain shapes and clearances. Buy the wrong clearance letter and it does not sit in the holder; misread the nose radius and your finish expectation is wrong. Decoding the code is the cheapest way to avoid buying the wrong part.

The nose radius field "08" = 0.8 mm, which connects directly to the roughness formula on page 03. The N clearance = negative rake connects to page 05: a strong insert for roughing, not a light finishing setup.

Worked Example

Given a roughing job on 4140 at 280 HB, you want a strong negative-rake insert. You decode a candidate CNMG 12 04 08: C = 80° shape, N = 0° clearance (negative rake, strong), nose radius 0.8 mm. That matches the requirement for a robust roughing insert — and the 0.8 mm nose radius sets your expected finish. You would not pick a positive-rake finishing code for this pocket.

Classroom assumption: the field meanings above follow the general ISO convention; exact tolerance and chipbreaker letters vary by manufacturer. Always confirm against the maker's code table for the actual insert.

Reading a catalog row

The designation is only the first line. A catalog entry also lists the recommended geometry, grade, chipbreaker, the cutting-speed band by material group, and whether the insert is for steel, stainless, cast iron or non-ferrous. Match all four to your job: shape and clearance set strength, nose radius sets finish (via Ra = f²/(32·rε)), chipbreaker set the chip control, and grade/coating set the speed and wear resistance. Buying on shape alone is a common beginner mistake — the same "CNMG 12 04 08" in a finishing steel grade and a roughing cast-iron grade behave very differently. When in doubt, the catalog's material-group recommendation is the safest starting point.

How the nose-radius field sets your finish

The last field is not a cosmetic detail — it is a finish specification. In CNMG 12 04 08, the 08 means rε = 0.8 mm. At the locked feed f = 0.10 mm/rev, the theoretical roughness is Ra ≈ f²/(32·rε) = 0.10²/(32·0.8) = 0.391 µm — a fine finish. If instead you picked a CNMG 12 04 04 (rε = 0.4 mm) at the same feed, the theory doubles to 0.781 µm. So before ordering, the drawing's required Ra already tells you which nose-radius field to look for: a fine finish pushes you toward 08 or larger, while a roughing pass where chatter matters wants a smaller radius. Decoding the code therefore connects directly back to page 05's trade-off between finish (large nose radius) and rigidity (small nose radius) — the designation string is where that choice becomes a part number.

Common Mistakes

  • Ordering by the whole string without decoding. You may get a clearance the holder cannot accept. Fix: decode shape and clearance before ordering.
  • Misreading the nose radius field. "08" means 0.8 mm, not 8 mm. Fix: treat the last two digits as tenths of a millimetre.
  • Ignoring that holders are pocket-specific. A CNMG does not fit a TNMG pocket. Fix: match insert shape to the holder pocket.

When you first read a catalog code, decode it field by field rather than guessing from the trade name: each letter or digit locks one decision — shape, clearance, tolerance, chipbreaker, size — and swapping one field silently changes the edge you actually receive. Always confirm the code against the actual pocket and holder before ordering, because two inserts that look similar can run at very different feeds.

When you read a catalog code, decode one field at a time and confirm it against the actual pocket before ordering: shape, clearance, tolerance, chipbreaker and size each lock a different decision. Two inserts that look similar can run at very different feeds, and a wrong field silently changes the edge you receive rather than failing loudly.

When two candidates differ by one letter, treat that as a real operational difference rather than a cosmetic catalog choice. Ask the supplier to confirm the pocket, chipbreaker and grade for your operation before you order a tray, because the label alone cannot tell you how the edge will run on your machine.

Practice

Q1. In CNMG 12 04 08, what is the nose radius?

0.8 mm (the "08" field, in tenths of a mm).

Q2. The "N" clearance means what?

0° clearance / negative rake — a stronger, more robust geometry.

Q3. Why must insert shape match the holder?

The holder pocket is ground for one insert shape; a different shape will not sit or clamp correctly.
