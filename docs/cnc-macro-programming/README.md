## Content Standards for Future Articles

Every new article should include a clear title, intended reader level, scope and controller boundary, safe-learning note where machine motion is discussed, concise examples, a practice or verification activity, and links to prerequisite and next-step topics. Add it to the relevant numbered category in this catalog and to the public website index.
