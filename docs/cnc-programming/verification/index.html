04.1 · Program Verification

Program Verification

Writing the program is half the job. Proving it won't crash the machine or scrap the part is the other half. This is the workflow every program should go through before cutting real material.

Verification Workflow

Never jump straight from writing the program to full-speed cutting. The most expensive crashes happen when someone assumes the program is correct. Even simple programs deserve a dry run. On a new part or a new operator, always run single block the first cycle.
