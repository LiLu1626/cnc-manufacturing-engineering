Common Formulas

  • RPM = Vc × 1000 / (π × D)
  • Feed (mm/min) = fz × flutes × RPM
  • Feed (mm/rev) = mm/min / RPM
  • Cutting time = distance / feed
  • MRR (mm³/min) = width × depth × feed
  • Tap feed = pitch × RPM
  • Drill tip height = (D/2) / tan(point_angle/2)

How to Read These Tables

This reference lists the most common G- and M-codes used on a typical Haas-style mill and lathe. The "Modal" column tells you whether the code stays active after one block (Yes) or applies only to the block it is called in (No). Group 00 codes (like G70/G71 on a lathe) are non-modal: they run once and then the machine returns to whatever motion mode was active before. If you expected G71 to stay on and it did not, check the modal group — it is not a bug, it is how the control is designed.

When in doubt, look up your exact controller model. FANUC, Siemens, Heidenhain, and Haas all use overlapping but not identical code sets. A code that means one thing on Haas may mean something else on FANUC — for example, G90 on a Haas lathe is a stock-removal cycle, not absolute mode. The startup block at the top of every program exists precisely to put the machine in a known state, so these differences cannot leak into the cut.

Use this page as a lookup, not as a tutorial. If a code here is unfamiliar, go back to the lesson that explains it — the code table alone will not teach you how to use it safely.

M-Codes Are Machine-Specific

M03/M04/M05 (spindle on fwd/rev/off) and M08/M09 (coolant on/off) are universal. M06 (tool change) on a Haas mill is a carousel rotation; on a machining center with a magazine it may be a 5-second ATC. M30 (program end and reset) returns to the top on Haas; M02 does not. The exact behavior of M-codes outside the universal list — M19 spindle orientation, M41/M42 gear range, M54 pallet change — is defined by the machine builder. Always check your manual before relying on a non-standard M code.

One block on Haas mills carries only one M code. If you need spindle on and coolant on, write two blocks: S1000 M03, then M08. Combining them in one block can alarm or ignore the second M on some controls. This is a Haas-specific rule; FANUC allows more than one M per block in some configurations.
