Quick Reference

A one-page lookup of the most common G-codes, M-codes, and formulas. Use this while working — not while learning.

Concept

M-Codes

CodeFunction
M03/M04/M05Spindle CW / CCW / stop
M06Tool change

M30Program end

Example

Formulas

  • RPM = Vc × 1000 / (π × D)
  • Feed (mm/min) = fz × flutes × RPM
  • Time = distance / feed
