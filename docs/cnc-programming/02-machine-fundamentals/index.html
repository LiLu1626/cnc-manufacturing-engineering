Machine Fundamentals for Programmers

Concept

Before writing code, you need to know what the code is controlling. You don't need to know how the servo motors work — but you do need to know which axes exist, which direction is positive, where the machine home is, and the difference between a CNC lathe and a CNC mill.

Why It Matters

If you write X100 on a lathe vs a mill, X means completely different things. If you don't know which direction is positive, your tool moves the wrong way. This lesson gives you the mental model to read any program.

The Linear Axes: X, Y, Z

AxisDirection on a MillDirection on a Lathe
XLeft / right on the tableRadial — diameter of the part
YIn / out of the tableNot used on a basic 2-axis lathe
ZSpindle up / downAlong the part length (spindle axis)

Right-hand rule: If you point your right thumb in the +Z direction, your fingers curl in the positive rotation direction. This is the universal CNC convention. +Z is away from the workpiece (up on a mill, away from the chuck on a lathe).

Rotary Axes: A, B, C

Rotary axes rotate about X, Y, and Z respectively. A-axis rotates about X, B about Y, C about Z. Most beginners start on 3-axis machines without rotary axes — but you'll see C-axis on lathes (for milling cross-holes) and A/B on 5-axis mills.

Machine Zero vs Workpiece Zero

Machine Zero (Home)Workpiece Zero (Part Zero)
What it isA fixed position the machine finds on startupWhere YOU decide the part origin is
Set byThe machine (via limit switches / encoder)You, during setup, by touching off
Stored inFixed in the controllerG54, G55, etc. — editable offsets
Changes whenNever (unless re-homed)Every time you re-setup the part

Lathe vs Mill: What a Programmer Sees

CNC LatheCNC Mill
AxesX (diameter), Z (length), optional CX, Y, Z, optional A/B/C
SpindleRotates the PARTRotates the TOOL
Tool holderTurret (indexes tools)ATC + magazine (Txx M06)
X valuesUsually programmed as diameter, not radiusActual distance
Typical toolsTurning, facing, boring, grooving, threadingEnd mills, drills, taps, face mills

Diameter programming on lathes: When you write X50. on a lathe, it means the tool is at a 50 mm diameter, not 50 mm from center. This is because you measure parts with calipers in diameter. If you forget this and think radius, all your turning dimensions are off by a factor of 2.

Practice Exercise

Question: On a vertical machining center, if you write G00 Z50., which direction does the tool move? Is that toward or away from the part?

Answer: +Z is up (away from the table). So Z50 means the tool moves up to 50 mm above the table — a safe retract position. If you wrote Z-50, it would plunge 50 mm below the table — that's a crash.
