Subprograms and Program Reuse

When you repeat a pattern, write it once as a subprogram and call it many times. This page builds a real 4-column × 3-row hole grid.

Level: KeyMachine: Mill
What you will learn:
  • How M98 P calls a subprogram and M99 returns
  • The L repeat-count parameter
  • Building a rectangular hole grid with incremental Y rows
  • Why the first G81 line drills at the current position

Concept

A subprogram is a separate program (identified by an O-number) called by M98 P and returned by M99. The main program positions the machine; the subprogram performs one repeating unit of work and returns. The L parameter on M98 tells the controller how many times to repeat the call.

Why It Matters

Without subprograms, drilling a 4×3 grid means 12 separate G81 lines. With a subprogram that drills one row of holes, the main program calls it three times. This shortens the program, reduces typo risk, and makes pattern changes easy.

Syntax — Haas Dialect

On Haas mills, the call uses P to specify the subprogram number (not O):

M98 P2000 L3   (call O2000 three times)

The O-number in the subprogram header identifies the program; the P-address in M98 references it. M99 at the end of the subprogram returns to the block after the M98 call.

Worked Example: 4×3 Hole Grid

Hole spacing: X = 20 mm, Y = 20 mm. First hole at (10, 10). Columns at X = 10, 30, 50, 70. Rows at Y = 10, 30, 50. Drill depth Z = −10, R plane at Z = +2.

Main program O1000:

O1000 (MAIN: 4x3 HOLE GRID)
G21 G17 G90 G80 G40 G49
T03 M06                 (6mm drill)
G54 S1500 M03
G43 H03 Z50. M08
G00 X10. Y10.           (position above first hole)
M98 P2000 L3            (call row subprogram, 3 rows)
G80 G00 Z50. M09 M05
G91 G28 Z0
M30

Subprogram O2000 (one row: 4 holes, then advance Y):

O2000 (ROW: 4 HOLES IN X, THEN Y+20)
G90 G81 Z-10. R2. F100.  (activates cycle, drills at current X=10,Y=10)
X30.                     (col 2 — G81 modal drills here)
X50.                     (col 3)
X70.                     (col 4)
G80                      (cancel cycle, retract to initial plane Z50)
G91 G00 Y20.             (incremental Y advance for next row)
G90 X10.                 (reset X to column 1, rapid at R-plane height)
M99

How the 12 Holes Are Produced

First call (main already at X10 Y10): G81 drills at (10,10), then X30 drills (30,10), X50 drills (50,10), X70 drills (70,10). G80 retracts. Y+20 moves to Y30. X10 resets. That is 4 holes.

Second call: G81 drills at (10,30), then (30,30), (50,30), (70,30). Y+20 to Y50. X10 reset. 4 more holes.

Third call: holes at (10,50), (30,50), (50,50), (70,50). Then G80, retract. Total: 12 unique holes, exactly 12 drill cycles.

Why No Redundant X10 Line

The first G81 line has no X/Y word. On Haas, a modal G81 with no new X/Y repeats the cycle at the current XY position. Since the main program already positioned at X10 Y10, that first line drills hole (10,10). Adding another X10 line would re-drill the same hole — 13 cycles for 12 positions. The X30/X50/X70 lines provide the new positions for columns 2–4.

Common Mistakes

  • Using M98 O2000 instead of M98 P2000 — Haas uses P for the subprogram address.
  • Adding a redundant X10 after G81 — re-drills the first hole.
  • Forgetting G90/G91 state reset — modal coordinates carry between main and subprogram.
  • Not resetting X after the Y advance — the next row starts at X70 instead of X10.
  • Assuming G80 is automatic — always cancel the cycle before rapid traversing at height.

Practice

1. How many drill cycles does M98 P2000 L3 actually produce?

Show answer

12. Each call drills 4 holes (X10 current position + X30 + X50 + X70), and the call repeats 3 times. No hole is repeated.

2. What happens if you write X10. on the line right after G81?

Show answer

The G81 cycle drills again at X10 — re-drilling the first hole that was already drilled by the no-X/Y G81 line. You would get 13 cycles for 12 positions.

3. Why is G80 needed before G91 G00 Y20?

Show answer

Without G80, the next XY move (Y20) would trigger another drill cycle at Z−10 — it would drill a hole while moving. G80 retracts to the initial plane before the Y advance.
