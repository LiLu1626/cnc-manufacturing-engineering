Modal State and Code Persistence

Modal codes are one of the most important and least understood concepts in G-code. This page explains what modal means and how it affects program execution.

Concept

A modal code stays active after it is commanded. Once G01 is on, every motion block remains G01 until G00, G02, or G03 replaces it. A non-modal code (like G53 or G04) is active for one block only.

Modal codes are organized into groups. Within a group, only one code can be active. Motion codes (G00/G01/G02/G03) are one group. Plane selection (G17/G18/G19) is another. Units (G20/G21) is another. Setting a new code in the same group cancels the previous one.

Why It Matters

Missing one line — like forgetting G80 after a drilling cycle — means the cycle stays active on the next hole. This is how programs drill holes at unexpected positions. Modal state errors are silent: the code looks fine, but the machine executes a different mode than you intended.

How It Works

Common Modal Groups

GroupCodesDefault
MotionG00, G01, G02, G03G00 at startup
PlaneG17, G18, G19G17
UnitsG20, G21G21 (mm)
DistanceG90, G91G90
CycleG80, G81, G82, G83, G84, G85G80

Example

G01 X10 F200
X50        (still G01, still F200)
Y30        (still G01, still F200)
G00 X0 Y0  (now rapid)

Lines 2 and 3 inherit G01 and F200. If the second line had been intended as rapid, you must explicitly write G00.

Common Mistakes

  • Forgetting G80 after drilling — the cycle continues on the next X/Y move.
  • Assuming G01 resets each line — it does not. Modal persists.
  • Mixing G90/G91 without tracking — switching modes mid-program without resetting causes coordinate errors.

Practice

1. After G81 R2. Z-15. F100, you write X30 Y20. What happens?

Show answer

The machine moves to (30,20) and drills another hole at R2 Z-15 F100. G81 is modal. You need G80 to cancel.

2. What cancels G41/G42?

Show answer

G40 cancels cutter compensation. It must be explicitly programmed.

3. Why is the startup block G21 G17 G90 G40 G49 G80 important?

Show answer

It resets all modal groups to known defaults, preventing leftover state from a previous program.
