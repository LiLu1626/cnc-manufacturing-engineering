Lesson 06 · Modal Codes

Modal vs Non-Modal Codes

Concept

A modal G-code stays active until another code in the same group cancels it. A non-modal code works only on the line it appears on. This is why you write G01 X50 F200 once, then X100, then X150 — G01 and F200 persist.

Why It Matters

New programmers often repeat G01 and F on every line (which works but is messy), or worse: they forget that a modal code from 20 lines ago is still active. Understanding modal groups prevents unexpected motion.

Example: Modal in Action

G01 X0 F200.       (G01 AND F200 are now active)
X50.               (still G01 at F200 — moves to X50)
X100.              (still G01 at F200 — moves to X100)
Y50.               (still G01 at F200 — moves diagonally to X100 Y50)
G00 X0 Y0          (G00 replaces G01 — rapid back to start)

Common Modal Groups

GroupModal codesWhat it controls
MotionG00, G01, G02, G03How axes move
Coordinate modeG90, G91Absolute vs incremental
UnitsG20, G21Inch vs mm
PlaneG17, G18, G19Which plane for arcs
Cutter compG40, G41, G42Tool radius compensation
Tool lengthG43, G49Length offset active
Feed modeG94, G95Feed per minute vs per rev

Only one code in each group can be active at a time. Writing G01 cancels G00. Writing G90 cancels G91. This is why the safe-start block (G21 G17 G90 G40 G49 G80) resets all groups to known values.
