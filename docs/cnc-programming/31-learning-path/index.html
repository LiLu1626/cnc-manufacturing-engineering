Learning Path & Checkpoints

Not sure what to learn next? This page gives you a sequenced path from zero to capable, with checkpoints to test yourself.

Concept

CNC programming is cumulative. Trying to learn subprograms before you understand coordinates is like building a house starting from the roof. This path sequences the material in dependency order.

Why It Matters

A structured path prevents the "I read everything but can't program anything" problem. Each checkpoint requires you to write and verify code before moving on.

How It Works

Level 1: Foundations

  1. What is CNC? → Machine axes
  2. Coordinate systems → G90/G91
  3. Program structure → G00/G01
  4. Spindle & feed → Work offsets
  5. Tool offsets → First program

Checkpoint: Write a 10-line milling program that faces a rectangular block.

Level 2: Machining

  1. Circular interpolation → Cutter comp
  2. Drilling cycles → Canned cycles
  3. Turning basics → G71/G70

Checkpoint: Complete the turning and milling projects.

Level 3: Advanced

  1. Subprograms → Verification
  2. Troubleshooting → Common mistakes
  3. CAM basics → Macro intro

Checkpoint: Read a random shop-floor program and explain every line.

Example

If you're starting now: do Level 1 first. Don't skip to G-code projects. Coordinates and offsets are the foundation; everything else builds on them.

Common Mistakes

  • Skipping levels — if you can't explain G90 vs G91, don't start subprograms.
  • Reading without practicing — every checkpoint requires writing code, not just reading.

Practice

1. What should you learn first?

Ans

Coordinate systems. Everything else depends on them.

2. When are you ready for subprograms?

Ans

When you can write and verify a basic drilling cycle with G81 and G80.

3. What's the Level 1 checkpoint?

Ans

Write a 10-line milling program that faces a rectangular block.
