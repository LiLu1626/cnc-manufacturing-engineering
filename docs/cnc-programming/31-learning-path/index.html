Your Learning Path

Level 1: foundations. Level 2: basic turning/milling. Level 3: intermediate cycles. Level 4: macros and automation.

Level: KeyMachine: All
What you will learn:
  • Level 1: 10 lessons to a basic program
  • Level 2: turning, milling, cycles
  • Level 3: subprograms, multiple tools
  • Level 4: macros, probing, automation

Concept

Do not learn G-codes in isolation. Build up: coordinate systems first, then motion, then offsets, then a complete program. Each lesson depends on the previous.

Practice

1. Which lesson should you start if you already know G00/G01?

Show answer

Jump to Lesson 13 (Work Offsets) — offsets are where mistakes happen.

2. Why learn subprograms before macros?

Show answer

Subprograms teach reuse; macros add variables and logic on top.
