01.2 · Coordinate Systems

CNC Coordinate Systems

This is the most important chapter for beginners. If you don't understand coordinates, every G-code will look like magic. By the end, you'll know the difference between machine zero, work zero, and how G54 connects them.

The Two Coordinate Systems

Machine Zero (Machine Home)

Every machine has a fixed reference point established by home switches. On startup, the machine "homing cycle" moves the axes until they hit the reference switches — this is machine zero. You don't change it. It's the machine's own internal origin.

Work Zero (Part Zero, Program Zero)

When you set up a part, you tell the controller where your part's origin is (e.g. the corner of the block). That offset is stored in G54. Now when you program G00 X50 Y20, the machine moves 50 mm in X and 20 mm in Y from your part's corner, not from machine zero.

Machine position = Machine zero + Work offset (G54) + Program coordinates

G54–G59: Multiple Work Offsets

Most controllers give you 6+ work offsets. Use them for:

  • G54: First part / first setup
  • G55: Second part on the same table
  • G56: Another setup or fixture

G90 (Absolute) vs G91 (Incremental)

This is the #1 beginner confusion. G90 means coordinates are always measured from work zero. G91 means each coordinate is a distance moved from the current position.

Example: Same code, different meaning

Start at X50. Which position do you end up at?

  • G90 G01 X120 → go to absolute position X=120. End at 120.
  • G91 G01 X120 → move 120 mm from current. End at 50+120 = 170.

Always know which mode you're in. Most manual programming uses G90 (absolute). G91 is useful for repeating patterns (e.g. drilling a hole grid).

Forgetting G90/G91 is a classic crash cause. If you think you're programming absolute but the machine is in incremental, every coordinate shifts by the previous position. When in doubt, check the controller's current modal state on screen.
