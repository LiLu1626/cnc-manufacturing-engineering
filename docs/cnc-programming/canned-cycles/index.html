03.3 · Canned Cycles

Canned Cycles

Drilling, pecking, tapping, boring — these repeated motions are packaged into single-line "canned cycles." Instead of writing 10 lines for each hole, you write one line and repeat.

Common Drilling Cycles

CycleWhat it doesUse for
G81Drill straight down, rapid outShallow holes, center drills
G82Drill, dwell at bottom, retractSpot faces, bottoming drills
G83Peck drill: drill in, retract to clear chips, repeatDeep holes, chip evacuation
G84Rigid tappingTapping threads
G85Bore: feed in, feed outReaming, boring
G80Cancel canned cycleAfter all holes done

Typical Cycle Structure

G90 G54 G00 X0 Y0 S2000 M03
G43 H01 Z50. M08
G81 G99 X20. Y20. Z-15. R5. F100.
X40. Y20.
X60. Y20.
G80 M09
G91 G28 Z0
M30

Cycle Parameters

ParameterMeaning
X__ Y__Hole position
Z__Final hole depth
R__R plane — where tool starts feeding and retracts to
F__Feed rate
G98/G99Retract to initial plane (G98) or R plane (G99)

G80 cancels the cycle. Without G80, the machine keeps drilling every X/Y move as if it's a hole position. Always write G80 when you're done drilling.
