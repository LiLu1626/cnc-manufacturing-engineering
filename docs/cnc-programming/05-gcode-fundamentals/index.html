G-Code Fundamentals

G-codes tell the machine what kind of motion to perform. This page covers the four core motion codes and how to use them safely.

Concept

G00 is rapid positioning: the machine moves as fast as possible to a target position. It is not a cutting move. G01 is linear interpolation: the machine moves in a straight line at a specified feed rate while cutting. G02 and G03 are circular interpolation (clockwise and counterclockwise).

G00 and G01 are modal: once you set G01, every subsequent motion block stays in G01 until another motion code replaces it.

Why It Matters

G00 moves at rapid speed (often 15-30 m/min). If the tool is not above the stock when you rapid, it crashes into the vise or part. The #1 cause of beginner crashes is unsafe G00 moves. Always make sure Z is at clearance before rapid in X/Y.

How It Works

G00 — Rapid

G00 X50. Y30.

Moves at maximum speed. No F word needed. Used for positioning, not cutting.

G01 — Linear Feed

G01 X50. Y30. F200.

Straight-line motion at feed rate. F stays modal.

G02/G03 — Circular

See Circular Interpolation for full detail.

Example

Safe approach pattern:

G00 X0 Y0        (rapid XY to above target)
G00 Z5.          (rapid Z to 5mm above stock)
G01 Z-2. F100.   (feed down to cut depth)
G01 X50. F300.   (feed cut)
G00 Z50.         (retract up before XY move)

Common Mistakes

  • Rapid XY at cut height — always retract Z to clearance before moving in XY.
  • Forgetting F on first G01 — the feed rate may default to a dangerous value.
  • Using G00 for cutting — G00 is positioning only; it does not cut.

Practice

1. When is G00 safe vs unsafe?

Show answer

Safe: tool is above clearance plane. Unsafe: tool is at cut depth or near stock/fixture. Always retract Z before rapid XY.

2. Distance 40 mm at F200. Time?

Show answer

40/200 = 0.2 min = 12 seconds.

3. Why is G00 not straight-line between axes?

Show answer

On many controllers, G00 moves each axis at its own maximum speed independently, not interpolated at a programmed feed. The cornering path may be diagonal first, then straight.
