Cutter Radius Compensation

Cutter compensation lets you program the part outline, not the tool center path. The controller offsets the tool by the radius. This page covers G41/G42 direction, lead-in/out, and the overcut error.

Concept

Without compensation, you program the tool center path — offset by the tool radius from the part edge. With cutter radius compensation (G41/G42), you program the part outline and the controller automatically offsets the tool center by the radius stored in the D offset.

G41 = left compensation (tool is left of the direction of cut). G42 = right compensation. G40 cancels.

Why It Matters

Getting G41/G42 backwards causes overcut: on an outer profile, if you pair the wrong direction with the wrong compensation, the tool pushes inside the part and cuts away material it should leave. The rule (G17, viewed from +Z above the table, positive D offset): outer profile cut clockwise (CW) uses G41; outer profile cut counterclockwise (CCW) uses G42.

How It Works

Lead-In / Lead-Out

Compensation must be activated on a straight lead-in move (at least tool radius long) before entering the contour, and canceled on a straight lead-out. Never activate G41/G42 directly on the part corner.

Direction Rule with a Coordinate Table

Program this outer rectangle clockwise: (0,0) → (0,50) → (50,50) → (50,0) → (0,0). Tool radius D=5. With G41, the tool center sits 5 mm to the left of each directed edge:

EdgeDirectionTool left of directionTool center midpoint
(0,0)→(0,50)+Y (up)−X (west)X=−5, Y=25
(0,50)→(50,50)+X (right)+Y (north)X=25, Y=55
(50,50)→(50,0)−Y (down)+X (east)X=55, Y=25
(50,0)→(0,0)−X (left)−Y (south)X=25, Y=−5

In every row the tool center falls outside the rectangle [0,50]×[0,50]. That is correct outer profiling. If you instead used G42 on this same CW path, the tool would shift inside and cut the part too small.

G00 X-10. Y-10.          (start outside, below-left)
G01 G41 X0. Y0. D01 F300.  (lead-in to corner, comp on)
G01 Y50.                   (left edge up)
G01 X50.                   (top edge right)
G01 Y0.                    (right edge down)
G01 X0.                    (bottom edge left)
G01 G40 X-10. Y-10.        (lead-out, comp off)

Example

Same rectangle, same coordinates, G41 throughout. The controller reads D01 = 5 mm and shifts the tool center to X=−5 on the left edge, Y=55 on the top edge, X=55 on the right edge, Y=−5 on the bottom edge. The programmed path stays on the part outline; the machine follows the offset boundary.

Common Mistakes

  • G42 on a CW outer profile — pushes tool inside, overcuts. Match: CW outer = G41, CCW outer = G42.
  • No lead-in move — compensation must ramp on a straight move, not instantly at a corner.
  • Forgetting G40 — compensation stays active into the next move, causing unexpected offsets.
  • Confusing inner and outer profiles — the left/right rule flips for pockets (inner walls). Always trace the directed edge and ask which side is air.

Practice

1. Outer rectangle cut clockwise: (0,0)→(0,50)→(50,50)→(50,0)→(0,0). G41 or G42?

Ans

G41. On the left edge going up (+Y), left is −X = outside. On the top edge going right (+X), left is +Y = outside. On the right edge going down (−Y), left is +X = outside. On the bottom edge going left (−X), left is −Y = outside. G41 keeps the tool outside on all four edges.

2. Why a lead-in move?

Ans

The controller needs a straight move to ramp the tool center from zero offset to full radius offset. Activating at a corner causes a sudden step.

3. What cancels G41/G42?

Ans

G40. Must be on a straight lead-out move.
