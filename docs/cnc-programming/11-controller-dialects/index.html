Controller Dialects

G-code is not universal. FANUC, Siemens, Heidenhain, and Haas share concepts but differ in syntax, cycles, and parameters. Always program for your actual controller.

What you will learn:
  • Why the same G-code means different things on different machines
  • Key differences: cycle format, subprogram calls, feed modes
  • Why copying code from the internet is dangerous

Major Controllers

  • FANUC: most common globally. Two-line G76, G94/G95 feed modes, M98 P subprogram calls.
  • Haas: simplified one-line G76 with K/D, G99 for feed/rev on lathes, M98 P calls.
  • Siemens (Sinumerik): uses CYCLE calls instead of G81/G83, different offset system.
  • Heidenhain: conversational-style programming, Q parameters instead of # variables.

Why It Matters

A program written for a Haas mill may alarm on a FANUC machine, and vice versa. This course uses Haas syntax as the reference dialect. Before transferring a program, check the controller's manual for the exact cycle format and parameter meanings.

Common Mistakes

  • Assuming G81 means the same thing on every controller — it often does, but R plane and retract behavior can differ.
  • Copying G-code from a textbook without checking the dialect.
  • Assuming M-codes are universal — many M-codes are machine-specific.

Practice

1. What does M98 P2000 do on a Haas?

Show answer

Calls subprogram O2000 once. The P-address specifies the program number.

2. Why should you not assume G-code from one machine works on another?

Show answer

Cycle formats, parameter meanings, and even G-code assignments vary by controller and manufacturer. Always verify against the machine's manual.
