Drilling & Hole-Making Programming

Concept

Hole-making operations (drilling, pecking, tapping, boring) use canned cycles — one line of code that packages the entire drill-down-retract sequence. This makes drilling a plate full of holes fast and clean.

Common Drilling Cycles

CycleWhat it doesUse for
G81Drill straight down, rapid outShallow holes, center drills, spotting
G82Drill, dwell at bottom, retractSpot faces, flat-bottom holes
G83Peck drill: drill in, retract to clear chips, repeatDeep holes, chip evacuation
G84Rigid tappingTapping threads
G85Bore: feed in, feed outReaming, boring
G80Cancel cycleAfter all holes done

Cycle Structure

G90 G54 G00 X0 Y0 S2000 M03
G43 H01 Z50. M08
G81 G99 X20. Y20. Z-15. R5. F100.   (hole 1)
X40. Y20.                              (hole 2 — same cycle)
X60. Y20.                              (hole 3)
G80 M09                                (cancel cycle, coolant off)
G91 G28 Z0
M30
ParameterMeaning
X__ Y__Hhole position
Z__Final hole depth
R__R plane — where feed starts and retracts to
F__Feed rate
G99Retract to R plane between holes
G98Retract to initial Z plane between holes

Always write G80 after drilling. Without G80, the machine treats every X/Y move as a new hole position and tries to drill. This is a classic beginner mistake.
