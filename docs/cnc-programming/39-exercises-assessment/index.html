Exercises & Assessment

Read the code, trace the tool path, find the bugs. These exercises build the habit of mentally simulating a program before running it on the machine.

Knowledge Check

  1. What does G01 do, and how is it different from G00?
    Answer

    G01 is linear interpolation at a controlled feed rate F. G00 is rapid positioning at machine maximum speed, no feed rate used for cutting.

  2. What is G54?
    Answer

    G54 is the first work coordinate system offset (work zero). It shifts the coordinate origin from machine zero to the workpiece datum.

  3. What is the difference between G90 and G91?
    Answer

    G90 = absolute programming: coordinates refer to the work zero. G91 = incremental programming: coordinates refer to the current tool position.

  4. What does G41 do?
    Answer

    G41 activates cutter radius compensation to the left of the programmed direction. The machine offsets the tool center by the radius stored in D code.

Trace

Assuming the machine starts at a safe Z height and G54 is set: 1. Rapid to XY (20,20). 2. Spindle on, rapid to Z50 with tool length offset H01. 3. Feed down to Z-2 at 100 mm/min. 4. Feed to X80 (still Y20) at 300 mm/min. 5. Rapid up to Z50. 6. Rapid to X0 Y0. 7. Program end.

Find the Error

This program has a bug. What happens, and how do you fix it?

G90 G54 G00 X0 Y0
G43 H01 Z50.
G01 Z-5. F100.
G01 X50.
G41 D05
G01 X80. Y30.
G00 Z50.
M30
Find it — with full corrected program

The bug: G41 is turned on mid-cut while the tool is already at Z-5, with no lead-in move. Cutter radius compensation needs a straight XY approach move from outside the part to build the offset over a distance of at least one tool radius. Also, the program never cancels with G40.

Assumptions: 10 mm end mill (D05 stores 5 mm radius), part is a 50×50 mm block from (0,0) to (50,50), cut depth Z-5, G17 XY plane.

Corrected program:

G90 G54 G00 X-10. Y-10.   (position outside part at Z50)
G43 H01 Z50. S2000 M03
G01 Z-5. F100.             (feed to cut depth)
G01 G41 X0 Y0 D05 F300.    (lead-in: 14.1 mm diagonal from outside, builds compensation)
G01 X50.                   (cut left edge)
G01 Y50.                   (cut bottom edge)
G01 X0                     (cut right edge)
G01 Y0                     (cut top edge)
G01 G40 X-10. Y-10.        (lead-out: back outside, cancels compensation)
G00 Z50. M05
M30

The lead-in from (-10,-10) to (0,0) is 14.1 mm — long enough for the controller to ramp in the 5 mm radius offset. The lead-out mirrors it. G40 must be active before retracting Z.
