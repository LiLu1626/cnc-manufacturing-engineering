Exercises & Assessment

Read the code, trace the tool path, find the bugs. These exercises build the habit of mentally simulating a program before running it on the machine.

Knowledge Check

  1. What does G01 do, and how is it different from G00?
    Answer

    G01 is linear interpolation at a controlled feed rate F. G00 is rapid positioning at machine maximum speed, no feed rate used for cutting.

  2. What is G54?
    Answer

    G54 is the first work coordinate system offset (work zero). It shifts the coordinate origin from machine zero to the workpiece datum.

  3. What is the difference between G90 and G91?
    Answer

    G90 = absolute programming: coordinates refer to the work zero. G91 = incremental programming: coordinates refer to the current tool position.

  4. What does G41 do?
    Answer

    G41 activates cutter radius compensation to the left of the programmed direction. The machine offsets the tool center by the radius stored in D code.

Trace

1. Rapid to (20,20) at safety height. 2. Spindle on, rapid to Z50 with tool length offset. 3. Feed down to Z-2 at 100 mm/min. 4. Feed to X80 (still Y20) at 300 mm/min. 5. Rapid up to Z50. 6. Rapid to X0 Y0. 7. Program end.

Find the Error

This program has a bug. What happens, and how do you fix it?

G90 G54 G00 X0 Y0
G43 H01 Z50.
G01 Z-5. F100.
G01 X50.
G41 D05
G01 X80. Y30.
G00 Z50.
M30
Find it

G41 is turned on mid-cut while the tool is already at Z-5, with no lead-in move. Cutter radius compensation needs a straight XY approach move (at least one tool radius long) from outside the part to build the offset. The fix: position the tool at a start point outside the part at Z50, feed to cutting depth, then use a linear G01 move toward the contour with G41 active. At the end, use a lead-out move and G40 to cancel. Example: position at X-10 Y-10 (outside), feed Z-5, then G01 G41 X0 Y0 D05 (lead-in), cut the contour, then lead-out and G40 before retracting Z. Always end with G40.
