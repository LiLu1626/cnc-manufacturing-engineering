Exercises & Assessment

Read the code, trace the tool path, find the bugs. These exercises build the habit of mentally simulating a program before running it on the machine.

Knowledge Check

  1. What does G01 do, and how is it different from G00?
    Answer

    G01 is linear interpolation at a controlled feed rate F. G00 is rapid positioning at machine maximum speed, no feed rate used for cutting.

  2. What is G54?
    Answer

    G54 is the first work coordinate system offset (work zero). It shifts the coordinate origin from machine zero to the workpiece datum.

  3. What is the difference between G90 and G91?
    Answer

    G90 = absolute programming: coordinates refer to the work zero. G91 = incremental programming: coordinates refer to the current tool position.

  4. What does G41 do?
    Answer

    G41 activates cutter radius compensation to the left of the programmed direction. The machine offsets the tool center by the radius stored in D code.

Trace

Assuming the machine starts at a safe Z height and G54 is set: 1. Rapid to XY (20,20). 2. Spindle on, rapid to Z50 with tool length offset H01. 3. Feed down to Z-2 at 100 mm/min. 4. Feed to X80 (still Y20) at 300 mm/min. 5. Rapid up to Z50. 6. Rapid to X0 Y0. 7. Program end.

Find the Error

This program has a bug. What happens, and how do you fix it?

G90 G54 G00 X0 Y0
G43 H01 Z50.
G01 Z-5. F100.
G01 X50.
G41 D05
G01 X80. Y30.
G00 Z50.
M30
Find it — diagnosis and corrected program

Bugs in the given program:

  1. G41 activated mid-cut at Z-5 — after G01 X50, the tool is already cutting at depth. Cutter compensation must be engaged during a lead-in move from outside the material, not mid-cut.
  2. No G40 at the end — compensation is never cancelled before retracting Z. This can cause a crash on the next tool.
  3. No startup block — missing G21 (units), G17 (plane), G94 (feed mode), G80 (cancel cycles), G49 (cancel length comp).
  4. The path is not a defined part geometry — X0Y0→X50→X80Y30 has no statement of where the stock is, so the programmer cannot know which side to compensate toward.

Assumptions for the corrected example: 10 mm end mill (D05 = 5.0 mm radius; Haas Setting 40 set to radius mode), 50×50 mm aluminum block from (0,0) to (50,50), cut depth Z-5. Tool is already loaded in the spindle, G54 and H01 offsets have been verified, and Z50 is above all fixturing.

Corrected outer-profile program:

G21 G17 G90 G94 G40 G80 G49
G54 S2000 M03
G43 H01 Z50. M08
G00 X-10. Y-10.           (rapid to outside corner at safe Z50)
G01 Z-5. F100.             (feed to cut depth)
G01 G41 X0 Y0 D05 F300.    (lead-in: 14.1 mm diagonal, ramp in 5 mm offset)
G01 Y50.                   (up left edge — left of +Y travel = -X, outside)
G01 X50.                   (right along top — left of +X travel = +Y, outside)
G01 Y0.                    (down right edge — left of -Y travel = +X, outside)
G01 X0.                    (left along bottom — left of -X travel = -Y, outside)
G01 G40 X-10. Y-10.        (lead-out back outside, cancels compensation)
G00 Z50. M09 M05
M30

Clockwise travel around the block with G41 keeps the tool center outside on every side. The lead-in and lead-out diagonal moves (14.1 mm) are long enough to ramp in/out the 5 mm radius. G40 must cancel before retracting Z.
