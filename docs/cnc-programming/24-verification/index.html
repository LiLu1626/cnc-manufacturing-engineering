Program Verification & First Article

Writing the program is only half the job. This page covers the verification workflow that separates a production programmer from someone who crashes machines.

Concept

Program verification is the process of checking that the program produces the intended part before committing to a full run. The sequence is: syntax review → coordinate review → offset review → simulation → dry run → single block → reduced feed → first part → inspection.

Why It Matters

Every crash started as a "should be fine" program. The verification steps exist because mental simulation is unreliable. A 5-second dry run at reduced feed catches errors that cost 4 hours of repair and a broken tool. The cost of verification is tiny compared to the cost of a crash.

How It Works

Before Hitting Cycle Start

  1. Verify units (G21 mm)
  2. Verify work offset (G54 set correctly)
  3. Verify tool offsets (H/D values loaded)
  4. Verify spindle direction and speed
  5. Verify Z clearance above stock
  6. Verify tool number matches physical tool

First Article

Run the first part at 50% feed and rapid. After each operation, measure. If dimensions are correct, increase feed to production. If not, stop and correct offsets.

Example

Checklist before first cut:

  • G21 G90 G17 active
  • G54 origin at correct corner/center
  • H01 length offset measured
  • Spindle S2000 M03 forward
  • G00 Z50 above stock (not at Z-5)
  • Tool T01 matches what's in spindle

Common Mistakes

  • Running full feed on first part — use 50% feed override until first part passes inspection.
  • Skipping dry run — dry run at rapid with tool above stock catches gross coordinate errors.
  • Trusting CAM simulation — CAM doesn't know if your G54 is wrong.

Practice

1. Why reduced feed on first article?

Ans

So you can hit feed hold if something looks wrong before the tool cuts into the part.

2. What three offsets must be verified?

Ans

Work offset (G54), tool length (H), tool radius (D).

3. CAM simulation looks perfect. What still might be wrong?

Ans

Work offset, tool length offset, tool number, units, spindle direction — anything in the physical setup that the CAM model doesn't know about.
