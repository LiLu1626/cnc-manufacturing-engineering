Coordinate Systems and Positioning

Understanding coordinates is the single most important foundational skill in CNC programming. This page covers Cartesian coordinates, the right-hand rule, machine vs work coordinate systems, work offsets G54–G59, and absolute vs incremental motion.

Why this matters: Every CNC program is ultimately a list of coordinates. If you misunderstand the coordinate system, nothing else matters — the program will move the tool to the wrong place every time.

1. Cartesian Coordinate System

A point in space is defined by its X, Y, Z coordinates relative to an origin. The Cartesian coordinate system uses three mutually perpendicular axes. On a vertical mill:

  • X axis — left/right movement of the table
  • Y axis — in/out movement of the table
  • Z axis — up/down movement of the spindle

Positive and negative directions follow the right-hand rule: point your right thumb in +X, your index finger in +Y, and your middle finger in +Z. On a standard vertical mill, +Z is up (away from the table), +X moves the table right, and +Y moves the table away from the operator. On a lathe, Z is along the spindle (away from the chuck = +Z) and X is radial (larger diameter = +X).

2. Machine Coordinate System

The machine coordinate system has its origin at machine zero (also called machine home or reference position). This is a fixed physical position established when the machine is turned on and homed — each axis moves to a home switch. The machine always knows its current position relative to machine zero through encoders or scales.

G53 switches to machine coordinates for one block only. It is non-modal and used for machine-specific positions like tool change or pallet change, never for part programming. Example: G90 G53 Z0 moves Z to machine home for one block.

3. Work Coordinate System (G54–G59)

The work coordinate system (WCS) has its origin at the workpiece datum — typically a corner or center of the part. You set this origin using a work offset. The machine stores multiple work offsets:

CodePurpose
G54Primary work offset (most common)
G55Second fixture / second workpiece
G56Third fixture
G57–G59Additional fixtures

The relationship is: Machine position = machine zero + work offset + programmed coordinate. You touch off the part corner with an edge finder or probe, enter that machine position into G54, and the controller computes the rest. This three-layer relationship is the core mental model of CNC.

4. Absolute vs Incremental Programming

This is where new programmers get confused. Two modes control how coordinates are interpreted:

ModeCodeMeaningExample
AbsoluteG90Coordinates refer to work zeroX50 = "go to X50"
IncrementalG91Coordinates refer to current positionX50 = "move 50 mm in +X"

Example: Start at X0. G90 G01 X50 ends at X50. G91 G01 X50 also ends at X50 (because you started at 0). But start at X20: G90 G01 X50 ends at X50; G91 G01 X50 ends at X70. The same number produces a different result depending on the mode. Always know which mode you are in, and always restore G90 after using G91 in a subprogram.

5. Why Coordinate Errors Are Dangerous

If the work offset is wrong by 2 mm in X, every hole and edge on the part shifts 2 mm. The program may look perfect on screen but the part is scrap. Coordinate errors are systematic — they affect every feature, not just one. This is why verifying G54 before the first cut is the most important safety step.

Common Mistakes

  • Forgetting to restore G90 after a G91 subroutine — subsequent absolute moves become incremental and accumulate errors.
  • Treating G53 as modal — it is non-modal and active only for the block it appears in.
  • Wrong corner for work zero — programming G54 on the wrong edge shifts all features.
  • Confusing diameter and radius on a lathe — lathe X is always diameter.

Practice

1. Point A is (5,8), point B is (-5,18). What are ΔX and ΔY?

Show answer

ΔX = -5 - 5 = -10 mm. ΔY = 18 - 8 = +10 mm.

2. In G91 mode from X20, you write X30. Where do you end up? Where would G90 put you?

Show answer

G91: X20 + 30 = X50. G90: X30. The same number means a different target depending on mode.

3. Machine zero is at (-300, -200). A hole is at (20,10) in work coordinates. What is its machine position?

Show answer

(-300+20, -200+10) = (-280, -190).

4. Why must you always return to G90 after a G91 subprogram?

Show answer

G91 is modal. If you leave it active, the next G90 program line that assumes absolute positioning will instead move incrementally, accumulating position errors.
