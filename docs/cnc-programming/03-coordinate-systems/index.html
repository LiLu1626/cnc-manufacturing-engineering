CNC Coordinate Systems

Concept

Every position a tool moves to is a coordinate. CNC uses the Cartesian coordinate system: X, Y, Z. But there are two coordinate systems you must understand: the machine's own (machine zero) and the part's (workpiece zero). The bridge between them is the work offset.

Why It Matters

This is the #1 source of beginner errors. If you don't understand the difference between machine coordinates and work coordinates, you will crash. If you mix up G90 and G91, your coordinates mean the wrong thing. This is the most important lesson in the entire course — take your time here.

1. Cartesian Coordinates

Just like math class: you have an origin (0,0,0), and each axis goes positive and negative. On a mill:

  • +X = table moves right
  • +Y = table moves toward you (away from the column)
  • +Z = spindle moves up (away from the table)

2. Machine Coordinate System

The machine has its own fixed zero point called machine zero or home. When you turn on the machine, it "homes" itself — the axes move to the limit switches and establish where (0,0,0) is for the machine. You never program machine coordinates directly; the controller uses them internally.

3. Work Coordinate System (G54)

The part is not sitting at machine zero. It's clamped somewhere on the table. During setup, you "touch off" the part corner: the tool touches the X edge, the Y edge, and the top surface. You press set, and the controller records the offset between machine zero and the part corner. That offset is stored in G54.

Machine Position + Work Offset (G54) = Work Coordinate

OffsetUse
G54Primary part setup
G55Second part on the table (e.g. second vise)
G56, G57Additional parts or fixtures
G58, G59Pallets or multi-setup jobs

4. Absolute vs Incremental (G90 vs G91) ⭐

This is the concept that confuses every beginner. G90 means coordinates are absolute — every X/Y/Z is measured from work zero. G91 means coordinates are incremental (relative) — every X/Y/Z is a distance from the current position.

Example: Same Destination, Different Meaning

Start at X0 Y0. You want to end at X50 Y20.

ModeCodeWhat the machine does
G90 AbsoluteG90 G01 X50. Y20."Go to position X50 Y20" (from work zero)
G91 IncrementalG91 G01 X50. Y20."Move 50 in X and 20 in Y" (from where you are now)

If you start at X10 Y5 and write G91 X50 Y20, you end up at X60 Y25 — not X50 Y20. That's the trap.

Most programs run in G90 (absolute). G91 is used for specific moves like G91 G28 Z0 (return to home: move to machine zero relative to current position). If you're ever unsure which mode you're in, look at the controller screen — it shows G90 or G91.

Practice Exercise

Question: You're at X20 Y10. You write G91 G01 X30. Y15.. Where do you end up? Now write the equivalent G90 code.

Answer: In G91, you move +30 in X and +15 in Y from current position: X50 Y25. The G90 equivalent is G90 G01 X50. Y25.
