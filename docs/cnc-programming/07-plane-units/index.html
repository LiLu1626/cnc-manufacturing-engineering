Planes, Units & Numeric Conventions

Plane selection and units seem trivial but cause real scrap parts. This page explains G17/G18/G19, G20/G21, and why 100 might mean 100 mm or 1.00 inch.

Concept

G17 selects the XY plane (mill default). G18 selects XZ plane (lathe default). G19 selects YZ plane. Plane selection matters for circular interpolation: I/J vectors and G02/G03 direction are interpreted in the selected plane.

G21 = metric (mm). G20 = inch. Everything in the program — coordinates, feeds, offsets — follows the active unit mode. Mixing mm and inch is catastrophic: a program written in mm run in inch mode cuts everything 25.4x smaller.

Why It Matters

A G20/G21 mismatch can produce parts that are 25.4 times too small or too large. Plane errors cause arcs to be in the wrong plane — the tool makes a circular move in XZ instead of XY, producing a groove instead of a circle. These errors are not caught by syntax checkers; they only show up when the part is measured.

How It Works

Plane Selection

  • G17 XY — milling, drilling, pocketing
  • G18 XZ — lathe turning, facing
  • G19 YZ — rare, typically special applications

Units

G21 mm: X25.4 means 25.4 mm. G20 inch: X1.0 means 1.0 inch. Always confirm units before running a program. On Haas, the default is set by a machine parameter; the G-code should still explicitly command G20 or G21.

Decimal Point

Most modern controllers accept 100. = 100.0 and 100 = 100.0. But some older systems interpret 100 without a decimal as 0.100 inch (or 0.01 mm). Always use decimal points in programs.

Example

Program in mm (G21): drill at X25.4 Y12.7. If you forget G21 and the machine defaults to G20 (inch), X25.4 means 25.4 inches = 645 mm — far outside the machine envelope. Always explicitly set units.

Common Mistakes

  • Omitting G21/G20 — relying on the machine default is dangerous; always set it explicitly.
  • Using G18 on a mill — G18 is for lathes; on a mill, circular moves will be in the wrong plane.
  • Writing 100 without decimal — ambiguous on older controllers; always write 100. or 100.0.

Practice

1. You program X10.5 in G21. What is the actual position in mm?

Show answer

10.5 mm.

2. Same number X10.5 in G20. What is that in mm?

Show answer

10.5 inches = 266.7 mm. This is why unit mismatch is catastrophic.

3. Which plane should a mill use for pocketing?

Show answer

G17 (XY plane). G18 would make circular moves in XZ.
