Plane Selection & Units

Plane Selection: G17, G18, G19

Circular interpolation (G02/G03) needs to know which plane you're working in. G17 is the XY plane (milling), G18 is XZ (turning), G19 is YZ.

CodePlaneCommon on
G17XY planeMilling machines (default)
G18XZ planeCNC lathes / turning
G19YZ planeRare, special setups

The plane determines which axes move for arcs and which I/J/K values are used. G17 G18 G19 are modal — set once at program start.

Units: G20 vs G21

CodeUnitsFeedCoordinates
G20Inchesinch/mininches
G21Millimetersmm/minmm

Units errors are catastrophic. If your program says G21 (mm) but the machine is in G20 (inch), every dimension is off by 25.4×. A 50 mm cut becomes 1270 mm. Always confirm units at program start. G21 should be in your safe-start block.
