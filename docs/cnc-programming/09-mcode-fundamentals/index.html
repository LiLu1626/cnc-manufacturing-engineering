Lesson 09 · M-Code Fundamentals

M-Codes — Machine Functions

Concept

G-codes control motion. M-codes control everything else: spindle, coolant, tool change, stops, and program end. They're called "miscellaneous" but they're essential.

Common M-Codes

CodeFunctionWhen you use it
M03Spindle forward (clockwise)Before cutting: S2000 M03
M04Spindle reverse (CCW)Rarely needed
M05Spindle stopAfter cutting, before tool change
M06Tool changeAfter T-code: T03 M06
M08Coolant onBefore cutting
M09Coolant offAfter cutting
M00Program stopMachine stops; press cycle start to continue
M01Optional stopOnly stops if operator turns the switch on
M30Program end & resetLast line of every program

Typical Program Flow

T01 M06          (1. Change tool)
G54 S2000 M03    (2. Work offset, spindle on forward)
G00 X0 Y0        (3. Position at safe height)
G43 H01 Z50. M08 (4. Tool length offset, coolant on)
... CUT ...
G00 Z50. M09     (5. Retract, coolant off)
M05              (6. Spindle stop)
G91 G28 Z0       (7. Z to home)
M30              (8. End program)

M-codes can be machine-specific. The list above is standard Fanuc-compatible. On different machines, chuck clamp, tailstock, and pallet functions use different M-codes. Always check your machine manual for non-obvious codes.
