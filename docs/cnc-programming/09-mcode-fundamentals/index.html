M-Codes: Machine Functions

G-codes control tool motion; M-codes control the machine itself — spindle, coolant, tool change, program stop. This page covers the common M-codes and the correct program start and end sequence.

Concept

If G-codes answer "where does the tool go," M-codes answer "what does the machine do." An M-code is a machine function: start the spindle, turn on coolant, change a tool, stop the program. M-codes are mostly non-modal (one-shot): they execute once when the block is read and then stop. Once M03 starts the spindle, it stays running until M05, but that is a physical state change, not a modal code group in the G-code sense.

A block can contain both motion and an M-code. A line like G00 X0 Y0 M08 tells the machine to rapid to X0 Y0 and turn coolant on. On most controls, the M-code executes after the motion completes (M03/M04/M05/M08/M09 timing is a machine parameter). This is why writing M08 on the same line as the first Z cut is usually safe: coolant starts as the tool arrives at the cut.

Why It Matters

A missing M05 before a tool change can be dangerous: the tool carousel may index while the spindle is still spinning. Forgetting M09 leaves coolant flooding after the program ends. Ending with M30 while the spindle is still running is a safety and housekeeping hazard. M-codes are not optional decoration — they are the on/off switches for the machine, and their order at start and finish prevents collisions and messy shutdowns.

M-codes are also the most machine-specific part of the program. The G-codes G00/G01/G90 are largely universal; M-codes are not. The same M-code can mean different things on a FANUC, a Siemens, or a Haas machine. Always verify against your machine manual before assuming a new M-code will do what you expect.

How It Works

Spindle: M03, M04, M05

M03 starts the spindle clockwise (forward, viewed from the spindle nose). M04 starts it counter-clockwise. M05 stops the spindle. The speed is set with the S word: M03 S2000 starts the spindle at 2000 RPM clockwise. On a mill, nearly all tools cut in M03; M04 is reserved for specific tooling or manual operations. On a lathe, M03 is the normal forward direction.

Always write M05 before M06 (tool change). Most machines will not allow a tool change while the spindle is running, but relying on that interlock is bad practice — stop the spindle explicitly. Also give the spindle a moment to reach speed before cutting: the line M03 S2000 starts acceleration; the tool should not plunge until the spindle is at speed. A short dwell or a safe move to clearance before the cut gives the spindle time to ramp up.

Coolant: M08, M09

M08 turns on coolant (flood, through-spindle, or mist depending on machine config). M09 turns it off. Write M08 after the spindle is at speed and the tool is at safe clearance, just before the first cut. Write M09 before retracting Z to a high position and before M30. Leaving M09 off at program end means the next operator opens the door to a flood.

Tool Change: M06, T

On a machining center, T02 M06 selects tool 2 from the magazine and loads it into the spindle. On a lathe, the turret moves to the tool station directly: T0202 selects tool 2 and its offset. M06 is a one-shot block; it does not persist. After M06, the tool length offset must be established with a G43 H word before Z moves.

T selects the tool number; H sets the length offset separately. Writing T02 M06 does not automatically load H02. You must write G43 H02 on the next safe Z move. This is a common beginner mistake: they change tools but forget the H offset, and the next tool cuts at Z0 from machine reference instead of from the work face.

Program Control: M00, M01, M02, M30

CodeFunctionUse
M00Unconditional program stopAlways pauses; press cycle start to continue. Used for mandatory inspections or chip clearing.
M01Optional stopPauses only if the optional-stop switch on the panel is on. Used for spot checks; skipped in production.
M02Program endStops the program without rewinding to the top. Rarely used today.
M30Program end and rewindStandard end: stops spindle/coolant as part of end, rewinds to program top for the next cycle.

M30 is the standard program end on nearly all modern controls. It rewinds the program pointer to Oxxxx so the next cycle starts from the top. M02 does not rewind, which is why it has largely disappeared from modern programs. On Haas, M30 ends the program and stops spindle/coolant as part of program end; confirm the behavior on your control.

Other Common M-Codes

M07 turns on mist coolant (some machines), M09 turns off all coolant. M19 orients the spindle (used for some tool setups). M08/M09 are the flood coolant pair. Chuck clamp/unclamp and tailstock functions use machine-specific M-codes (often M10/M11 or similar). These vary by builder — do not assume.

M-Code Timing: Before or After Motion

On most FANUC/Haas controls, an M-code on the same line as motion executes after the motion completes. This matters: writing G00 Z50. M05 means Z retracts first, then the spindle stops. Writing M05 G00 Z50. on some controls may stop the spindle before the move. The safe habit is to put M05 and M09 on their own lines after the retract, so the order is explicit. Tool change M06 always waits for the spindle to stop and the tool to be in the correct position; the machine interlocks this, but writing the sequence out explicitly is clearer.

Program Stop, Optional Stop, and Program End

M00 is an unconditional stop: the program pauses, the operator can clear chips, measure the part, or change inspection tools, and presses cycle start to continue. M01 is an optional stop: it pauses only when the optional-stop toggle on the control panel is on. In production, the toggle is off and M01 is skipped; in first-article or setup runs, the toggle is on and M01 pauses for inspection. This is how the same program works for both production and setup without editing.

M02 and M30 both end the program. M02 stops without rewinding; M30 stops and rewinds the pointer to the program top so the next cycle starts from Oxxxx. On modern controls M30 also stops spindle and coolant as part of program end. Always use M30 at the end of a mill or lathe program.

Chuck, Tailstock, and Workholding M-Codes

On a lathe, chuck clamp/unclamp and tailstock extend/retract use machine-specific M-codes (often M10/M11 or similar). These are not standardized: a Haas lathe and a Mazak lathe may use different numbers for the same action. Never type a chuck M-code from memory — look it up. On a machining center, pallet change, fourth-axis clamp, and probe M-codes are also builder-specific.

Program Number and Block Structure

A FANUC/Haas mill program starts with O0001 (or O1001) and ends with M30. Each line is a block. Blocks can be numbered N10, N20, but numbers are optional. The program number Oxxxx is the file name on the machine. Comments in parentheses after a block are ignored by the controller but read by the operator: (DRILL 4 HOLES). Write comments that explain why, not what — the code already says what it does.

Safety: Why the Start Block Matters

The startup block G21 G17 G90 G40 G49 G80 establishes a known state. Without it, the program inherits whatever mode the previous program left: inch units, incremental coordinates, cutter compensation, or an active drilling cycle. The startup block does not set spindle, coolant, or work offset — those are set by later lines. It only resets the modes that cause silent motion errors. This is why every program on a shop floor begins the same way, and why copying a program without the startup block is dangerous.

Example: Full Program Start and End

A complete program on a Haas mill, classroom example (not a production cycle):

O0001 (DEMO PROGRAM)
G21 G17 G90 G40 G49 G80   (startup block)
T01 M06                    (load tool 1)
G54 G90 S1500 M03          (work offset, spindle forward)
G00 X0 Y0                  (position over part)
G43 H01 Z50. M08           (tool length offset, coolant on)
G00 Z5.
G01 Z-2. F100.
G01 X50. F300.
...
G00 Z50.                   (retract)
M09                        (coolant off)
M05                        (spindle stop)
G91 G28 Z0                 (return Z home)
M30                        (end, rewind)

Read the start block: T01 M06 loads the tool, G54 selects the work offset, S1500 M03 starts the spindle, G43 H01 applies the tool length, M08 turns on coolant. Read the end block: Z retract, M09 coolant off, M05 spindle stop, G28 return, M30 rewind. The order at the end is deliberate — coolant and spindle are off before the program ends.

Spindle Orientation and M19

M19 orients the spindle to a fixed position (used for some tool setups, boring bar orientation, or probe alignment). On a Haas, M19 with an R word can orient to a specific angle. This is not a cutting function; it is a setup function. You rarely see M19 in a production program, but it appears in probing and boring macros. After M19, the spindle stays oriented until M03/M04 or another motion command releases it.

Coolant: Flood, Mist, and Through-Spindle

M08 turns on coolant, but which coolant depends on machine configuration. Most mills have flood coolant; some have through-spindle coolant (TSC) for deep holes. M07 may turn on mist coolant on some machines. M09 turns off all coolant. TSC is especially useful for deep-hole drilling because it pushes chips out through the flutes and cools the drill tip. When using TSC, ensure the tool is rated for through-spindle pressure; a standard end mill may leak or fail under high pressure.

Tool Change Sequence on a Machining Center

A typical tool change block looks like T02 M06. The machine first moves Z to the tool-change position (if configured), stops the spindle, unclamps the current tool, indexes the magazine to tool 02, clamps the new tool, and returns. After M06, you must establish the tool length offset with G43 H02 on a safe Z move. The tool number T02 and the offset number H02 are independent: you can call T02 with H05 if needed, though the common practice is to match them. On a lathe, the turret indexes directly: T0202 selects station 2 and offset 2 in one block.

Why M-Codes Are Not G-Codes

A common beginner confusion is treating M-codes as if they were modal G-codes. M03 starts the spindle and it keeps spinning until M05, but that physical persistence is not the same as a modal G-code group. You do not need to re-write M03 on every cutting line, but you also cannot cancel M03 with another M-code the way G01 cancels G00. Spindle and coolant are physical actuators; G-codes are modes. Mixing the two mental models causes errors like expecting M08 to cancel a drilling cycle. Remember: M-codes turn actuators on and off; G-codes set modes.

Checking M-Code Effects Before Running

When a program uses an unfamiliar M-code, look it up in the machine manual before cycle-start. A wrong M-code can unclamp the chuck, flood coolant unexpectedly, or move the pallet. Most modern machines show the M-code function on the screen when you single-block through it; use that as a checklist on the first run.

Common Mistakes

  • Forgetting M05 before tool change — changing tools with the spindle running is dangerous. Write M05 explicitly.
  • Starting spindle before the tool is clear — position the tool at safe Z, then M03. Do not start the spindle while the tool is near the part.
  • Assuming M06 sets the tool offset — T selects the tool number; H sets the length offset separately. T02 M06 does not automatically load H02.
  • M30 without M09/M05 — the program ends but coolant and spindle stay on. Follow the retract, M09, M05, M30 order.
  • Using M02 instead of M30 — M02 does not rewind to program top. M30 is the standard end command.
  • Assuming M-codes are universal — M-codes are machine-specific. The same number may do different things on another control. Verify against the manual.
  • M08 on the first plunge without clearance — turn coolant on after the tool is at Z5 clearance, not while it is still above the fixture.

Practice

1. What does M01 do?

Show answer

Optional stop — pauses only if the optional-stop switch on the panel is on. Used for spot checks; skipped during production runs.

2. Why M09 before M05 at program end?

Show answer

Turn off coolant first, then stop the spindle. This prevents coolant from flooding after shutdown and ensures a clean stop. Never M30 with spindle or coolant active.

3. What is the difference between M00 and M01?

Show answer

M00 always stops (unconditional). M01 stops only if the optional-stop switch is on. M01 is used for spot checks; M00 is for mandatory pauses.

4. After T02 M06, what must happen before the first Z cut?

Show answer

A G43 H02 tool length offset must be applied on a safe Z move. T02 selects the tool; it does not load the H offset.

5. Why is M30 preferred over M02?

Show answer

M30 rewinds the program pointer to the top for the next cycle; M02 does not. On most modern controls M30 also ends spindle/coolant as part of program end.
