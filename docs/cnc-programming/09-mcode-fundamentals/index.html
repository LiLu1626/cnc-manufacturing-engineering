M-Codes: Machine Functions

G-codes control tool motion; M-codes control the machine itself — spindle, coolant, tool change, program stop. This page covers the common M-codes and the correct program start/end sequence.

What you will learn:
  • M03/M04/M05 spindle start/stop/direction
  • M08/M09 coolant on/off
  • M06 tool change
  • M00/M01/M02/M30 program control

Concept

M-codes cause machine actions independent of axis motion. Where G01 says "move in a straight line," M03 says "start the spindle." M-codes are non-modal for the most part: they execute once when the block is read. Unlike G-codes, most M-codes do not persist across blocks.

Important: M-codes are machine-specific. The same M-code may do different things on different machines. Always verify against your machine manual. The codes above are standard on FANUC/Haas; Siemens and Mazak may differ.

Why It Matters

A missing M05 before a tool change can be dangerous: the tool carousel indexes while the spindle is still spinning. Forgetting M09 leaves coolant flooding after the program ends. M30 with spindle still running is a safety hazard. The order of M-codes at program start and end matters.

The Correct Program End Sequence

G80                 (cancel cycles)
G00 Z50.            (retract Z to safe height)
M09                 (coolant off)
M05                 (spindle stop)
G91 G28 Z0          (optional: return Z to machine home)
M30                 (end program, rewind)

The order: coolant off first, then spindle stop, then program end. Never M30 with spindle still running or coolant still on. On a lathe, the sequence is similar: M09, M05, then retract and M30.

Common Mistakes

  • Forgetting M05 before tool change — changing tools with the spindle running is dangerous. Always M05 first.
  • Starting spindle before the tool is clear — position the tool at safe Z, then M03. Do not start the spindle while the tool is near the part.
  • Assuming M06 sets the tool offset — T selects the tool number; H sets the length offset separately. T02 M06 does not automatically load H02.
  • M30 without M09/M05 — the program ends but coolant and spindle stay on.
  • Using M02 instead of M30 — M02 does not rewind to program top. M30 is the standard end command.

Practice

1. What does M01 do?

Show answer

Optional stop — pauses the program only if the optional-stop switch on the machine panel is on. Used for inspection at chosen points; skipped during production runs.

2. Why M09 before M05 at program end?

Show answer

Turn off coolant first, then stop the spindle. This prevents coolant from flooding after shutdown and ensures a clean stop. Never M30 with spindle or coolant active.

3. What is the difference between M00 and M01?

Show answer

M00 always stops the program (unconditional). M01 stops only if the optional-stop switch is on. M01 is used for spot checks; M00 is for mandatory pauses.
