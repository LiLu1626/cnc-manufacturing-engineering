Macro Programming Foundations

Macro programming adds variables and logic to G-code. This page introduces the concepts without going deep — it's the entry point to advanced automation.

Concept

Macro programming adds variables (#1, #2), arithmetic, and logic (IF, WHILE) to CNC programs. Instead of hard-coding every hole position, a macro calculates them. Instead of repeating 20 lines, a macro loops.

Why It Matters

Basic G-code can only do what you explicitly write. Macros let the machine compute coordinates on the fly — perfect for bolt circles, hole patterns, and probing cycles. This is the difference between a program that does one thing and a program that adapts.

How It Works

Variables

#1 = 10.        (set #1 to 10)
#2 = #1 * 2     (#2 = 20)
G00 X#1 Y#2     (move to X10 Y20)

Logic

IF [#1 GT 10] GOTO 100
WHILE [#2 LT 50] DO 1
  (body)
  #2 = #2 + 5
END 1

Example

Bolt circle: 6 holes on R30. Macro computes each hole:

#1 = 0           (angle)
WHILE [#1 LT 360] DO 1
  #2 = 30 * COS[#1]
  #3 = 30 * SIN[#1]
  G90 G81 X#2 Y#3 R2. Z-10. F100.
  #1 = #1 + 60
END 1
G80

Six holes, one loop. Change the radius or count and the macro adapts.

Common Mistakes

  • Using macros before mastering basic G-code — you must understand coordinates and offsets first.
  • Integer vs real variables — #1 = 5 is integer; #1 = 5.0 is real. Be explicit.
  • Controller-specific syntax — macro syntax varies between FANUC, Haas, Siemens.

Practice

1. What is #1 = 10 used for?

Ans

A variable holding 10 mm, used in coordinates or calculations.

2. Why loops instead of writing 20 holes?

Ans

Easier to maintain: change one parameter and all holes update.

3. Should you learn macros first or after basic G-code?

Ans

After. Macros build on coordinates, offsets, and canned cycles.
