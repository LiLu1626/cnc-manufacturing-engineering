Macro Programming Foundations

Macros add variables, arithmetic, and logic to G-code. They let you write one program that drills any bolt circle, bores any diameter, or repeats any pattern.

What you will learn:
  • Local (#1-#33) and common (#100+) variables
  • Arithmetic: +, -, *, /, SQRT, COS, SIN
  • IF/GOTO conditional branching to N labels
  • WHILE/DO loops
  • Input validation before motion

Variables

Variables like #1, #2 store numbers. #1-#33 are local (lost when the program ends); #100+ are common (retained between programs). Assign with #1 = 20.

Branching and Loops

IF[#1 LE 0] GOTO 100    (conditional jump to N100)
WHILE[#3 LT #2] DO 1    (loop while #3 < #2)
  ...
  #3 = #3 + 1
END 1

GOTO takes a bare number matching an N label. Do not write "GOTO N100" — the N is only on the label block.

Why It Matters

Macros turn a fixed 4-hole program into a parameterized bolt circle: change #1 (radius) and #2 (hole count), and the same code works. See Macro Programming — Worked Example for the bolt-circle drill macro with integer validation.

Common Mistakes

  • Writing GOTO N100 instead of GOTO 100.
  • Not validating inputs — a zero radius divides by zero.
  • Forgetting that trig functions use degrees, not radians.

Practice

1. What is the correct way to jump to the block marked N200?

Show answer

GOTO 200 — bare number, no N in the GOTO statement.

2. Why validate inputs before motion?

Show answer

A zero or negative radius, or a non-integer hole count, produces wrong positions or crashes. Catch bad input with IF/GOTO before any G81.
