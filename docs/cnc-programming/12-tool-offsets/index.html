Tool Length and Tool Radius Offsets

The machine knows where the spindle face is. It does not know where the tool tip is. Tool length offsets bridge that gap — and the sign direction is critical.

Level: KeyMachine: Mill
What you will learn:
  • Why the machine needs tool length compensation
  • The signed geometry chain from program to machine to tip
  • What happens when stored length differs from actual length
  • Tool length offset (H) vs tool radius offset (D)

Concept

On a machining center, the spindle nose is a fixed reference point. Every tool that fits into the spindle has a different length. The controller knows the spindle position, but it does not know how long the tool sticking out below it is. G43 Hxx tells the controller the stored length of the current tool, so it can compute where the tool tip actually is.

The Geometry Chain

Define four values (signed, with Z positive up):

  • W — workpiece zero in machine Z coordinates (from G54).
  • P — programmed tool-tip position in work coordinates (what you write in the G-code).
  • H — stored tool length in the H offset (a positive number).
  • L — actual physical tool length (a positive number).

The controller commands the spindle reference plane to position M such that:

M = W + P + H

The actual tool tip in work coordinates is then:

Tipactual = M − L − W = P + H − L

Why It Matters

If the stored H equals the actual L, then Tipactual = P — the tool tip goes exactly where you programmed. If H and L differ, the tip lands offset by the difference.

Case 1 — stored H is too small (tool is longer than stored): H < L, so Tipactual = P + (H − L) < P. The tip goes lower (more negative) than programmed. A longer tool with an under-stored H cuts deeper.

Case 2 — stored H is too large (tool is shorter than stored): H > L, so Tipactual = P + (H − L) > P. The tip goes higher than programmed. A shorter tool with an over-stored H cuts shallower.

Worked Example

Given: G54 work offset W = −400 mm. You program the tip to P = +10 mm (10 mm above the part surface). Stored H = 100 mm.

The controller commands M = −400 + 10 + 100 = −290 mm.

If the tool is exactly 100 mm long (L = 100): Tip = 10 + 100 − 100 = +10. Correct.

If the tool is actually 102 mm long (L = 102): Tip = 10 + 100 − 102 = +8. The tip is 2 mm lower than programmed — 2 mm too deep when you expected to be 10 mm above the surface.

Now program a cut at P = −10 (10 mm deep into the part). With L = 102: Tip = −10 + 100 − 102 = −12. The cut is 2 mm deeper than programmed.

G43, G49, and What They Actually Do

G43 Hxx activates tool length compensation using the value stored in offset number xx. After G43, the controller adds H to every Z move so that programmed coordinates refer to the tool tip, not the spindle face.

G49 cancels tool length compensation. After G49, Z moves refer to the spindle face position. Important: G49 does NOT switch the machine to machine coordinates and does NOT cancel G54. The work offset remains active; only the tool length compensation is removed. G53 is the code that refers directly to machine coordinates — G49 is not G53.

Tool Radius Offset (D) — Different Thing

The H offset handles Z (tool length). The D offset handles tool radius in X/Y (cutter compensation, Lesson 16). They are separate registers. Do not confuse "tool offset" (H, axial) with "cutter radius offset" (D, radial).

Common Mistakes

  • Swapping a tool without updating its H value — a longer tool cuts deeper; a shorter tool cuts shallower.
  • Thinking G49 puts the machine in machine coordinates — it only cancels length compensation; G54 stays active.
  • Confusing H (length, Z) with D (radius, X/Y).
  • Forgetting that H values are stored per tool number — T02 may use H02, but you must call G43 H02 explicitly.

Practice

1. Stored H = 100 mm, actual tool length = 105 mm. You program Z = −20. Where does the tip actually go?

Show answer

Tip = P + H − L = −20 + 100 − 105 = −25. The cut is 5 mm deeper than programmed.

2. After G49, is the machine in machine coordinates?

Show answer

No. G49 cancels tool length compensation only. G54 work offset remains active. To refer to machine coordinates directly, use G53.

3. You replace a 100 mm tool with a 98 mm tool but forget to update H. Does the cut go deeper or shallower?

Show answer

Shallower. H = 100, L = 98, so Tip = P + 100 − 98 = P + 2. The tip ends up 2 mm higher than programmed.
