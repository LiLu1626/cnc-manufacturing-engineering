Tool Length & Geometry Offsets

The machine knows where the spindle is, but it does not automatically know where the tool tip is. Tool offsets bridge that gap. This page covers G43 length compensation, geometry vs wear, and tool radius.

Concept

Every tool has a different length and radius. The machine's Z axis position measures the spindle nose, not the cutting tip. Tool length offset tells the controller how much longer (or shorter) this tool is than a reference. G43 H01 activates length compensation using offset register 1. G49 cancels it.

On a lathe, each tool has a geometry offset (the base position) and a wear offset (small corrections). The actual tool tip position = machine position + geometry offset + wear offset. The machine knows machine position; the offset table tells it where the tip is.

Why It Matters

If tool length offset is wrong, the Z depth is wrong. A tool that is 5 mm shorter than the offset thinks it is at Z-5 when it is actually at Z0 — it will not cut. If it is 5 mm longer, it cuts 5 mm too deep. On a lathe, wrong X offset means wrong diameter — directly on the part tolerance.

How It Works

Mill: G43 Length Compensation

G00 G43 H01 Z50.  (activate length comp with offset 1, go to Z50)

The controller adds the H offset to the commanded Z. If H01 = -120.0 (tool is 120 mm shorter than reference), the actual spindle position becomes Z170.0, and the tip is at Z50. G49 cancels length comp — but G49 does not switch to machine coordinates (that is G53). It simply removes the length offset from the current position.

Geometry vs Wear

  • Geometry offset — the measured base offset for this tool (set during setup).
  • Wear offset — small corrections as the tool wears (e.g., -0.02 mm when diameter is oversized).

Lathe: Tool Nose Radius

Turning tools have a nose radius (e.g., r0.4). The virtual tip (intersection of X and Z extensions) is what the geometry offset references. The actual nose leaves a small fillet at sharp corners.

Example

Tool 1 length = 150 mm. Reference tool length = 150 mm (H01 = 0). Tool 2 length = 145 mm. H02 = -5.0 mm.

Program: G00 G43 H02 Z50. The spindle goes to Z55.0 (50 + 5), and the tool tip reaches Z50.0. Without G43, the spindle would go to Z50.0 and the tip would be at Z45.0 — 5 mm too low.

Common Mistakes

  • Thinking G49 returns to machine coordinates — G49 cancels length offset only. G53 is machine coordinates.
  • Using H number as tool number — H01 is offset register 1, not necessarily tool 1. They usually match but are independent.
  • Confusing geometry and wear offsets — geometry is for setup; wear is for in-process correction.

Practice

1. H01 = -80.0. You command G43 H01 Z30. Where does the spindle actually stop?

Show answer

Spindle at Z = 30 - (-80) = Z110. The tip is at Z30.

2. What is the difference between G49 and G53?

Show answer

G49 cancels tool length compensation. G53 switches to machine coordinate system for one block. They are unrelated.

3. You measure a turned diameter at 30.05 mm. Target is 30.00. What wear offset do you apply?

Show answer

The cut is 0.05 mm too large (diameter). Adjust X wear by -0.05 mm.
