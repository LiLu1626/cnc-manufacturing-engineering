Tool Management & Tool Offsets

Concept

The machine knows where the spindle nose is. It has no idea how long your tool is, or how wide. Tool offsets teach the controller each tool's geometry so the tip ends up where the program expects.

Why It Matters

If the machine moves Z to "Z0" but your tool is 120 mm long vs the expected 100 mm, the tip cuts 20 mm too deep. That's a scrapped part or a broken tool. Offsets are how you bridge that gap.

Tool Length Offset (Milling)

Every tool in the magazine has a different length. G43 H01 tells the controller: "apply the length offset stored in register H01."

CodeMeaning
G43 H01Activate tool length offset from H01
G49Cancel tool length offset

Geometry vs Wear Offset

Offset typeWhat it storesWhen to update
Geometry offsetThe tool's measured length and radiusWhen you install a new tool
Wear offsetFine correction as the tool wearsDuring production, as dimensions drift

Turning Tool Offsets

On a lathe, each turret station has a geometry offset. You also set the tool nose radius and tool tip orientation (which corner of the insert is used) — these matter for G41/G42 radius compensation on turned contours.

Machine position + Work offset + Tool length offset = Actual tool tip position

Always cancel G49 at program end (or rely on the safe-start block). If tool length offset is left active, the next program starts with an incorrect Z position. This is a classic crash cause.
