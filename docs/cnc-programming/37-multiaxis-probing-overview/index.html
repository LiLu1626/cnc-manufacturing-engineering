Rotary Axes & Probing Overview

Rotary axes and probing extend what a CNC machine can do. This page introduces A/B/C axes, touch probes, and 3+2 machining without going deep into 5-axis programming.

Concept

Rotary axes (A, B, C) rotate the tool or workpiece around the linear axes. A rotates around X, B around Y, C around Z. A touch probe measures part position and feeds back into work offsets automatically.

Why It Matters

Without probing, setting work offset on a complex fixture is manual and error-prone. A probe touches the part, calculates the edge/center, and sets G54 automatically. Rotary axes let you machine multiple sides without re-fixturing — reducing setup error and cycle time.

How It Works

3+2 vs Full 5-Axis

  • 3+2 — rotary axes position once, then XYZ linear milling. Simpler programming.
  • Full 5-axis — rotary and linear move simultaneously. Complex CAM required.

Probing Basics

A touch probe mounts in the spindle. It moves to the part, touches it, and records the position. The controller computes the offset. The measured coordinate is not directly G54 — it must be converted: edge touch = half stock offset from center.

Example

Probe a 60 mm square part edge: touch left edge at X-30, touch right edge at X+30. Center X = (X-30 + X+30)/2 = X0. Set G54 X to the machine position at X0. This replaces manual edge-finding.

Probe Applications

Beyond setting work offsets, probes are used for:

  • Fixture verification — confirm the part is clamped before cutting.
  • Work offset update — auto-set G54 after each job change.
  • In-process inspection — measure a feature mid-cycle and adjust offsets.
  • Tool setting — measure tool length and diameter automatically.
  • First-article check — probe critical dimensions after the first cut.

What a Probe Actually Does

A touch probe is a precision switch mounted in the spindle or turret. When the stylus touches the part, the switch triggers, and the controller records the current machine coordinate. By touching two opposite faces, the controller computes the center and writes it into a work offset. This replaces manual edge-finding and dramatically reduces setup time on repetitive parts. The probe itself is a precision instrument — it must be calibrated, the stylus must be clean, and the touch speed must be slow enough to avoid bending the stylus.

Probing is not limited to setting G54. In production, a probe can: (1) find the part on a tombstone and write G54, G55, G56, G57 automatically; (2) measure a bore after boring and compare it to the nominal, adjusting the boring bar offset if needed; (3) detect a missing or misloaded blank before the program crashes; (4) measure tool length after a tool change and update H automatically. Each of these uses the same physical device but a different macro routine.

Multi-axis (rotary) probing is a separate topic. On a 4- or 5-axis machine, the probe can touch a bore on a tilted face, or measure a part after a C-axis rotation. The math is more complex because the probe point is in a rotated coordinate system, but the principle — record machine position at trigger, compute part position — is the same. Start with 3-axis probing before attempting rotary probing.

A probe crash can damage the stylus, the probe body, and the part. Cost depends on the probe model and setup — check your machine's manual and your shop's procedure. Always run probing routines at reduced feed override first, and keep a clear air approach distance before the touch move.

Common Mistakes

  • Treating probe reading as G54 directly — the probe touches an edge, not the center. Convert: center = (edge1 + edge2)/2.
  • Probing at high feed — probe feed must be set per the probe and controller manufacturer; too high a feed risks breaking the stylus. Use the recommended feed for your device.
  • Confusing 3+2 with full 5-axis — 3+2 positions rotary once; full 5-axis interpolates simultaneously.
  • Forgetting probe calibration — the stylus length and radius must be calibrated on a reference sphere before probing.

Rotary Axes: A, B, C in One Paragraph

A rotary axis rotates the workpiece (or the spindle). On a mill, a trunnion or rotary table adds A (rotation around X) and B (rotation around Y), or C (rotation around Z). On a lathe, the C axis indexes the spindle so you can mill flats or drill cross-holes while the part is held. A 4-axis machine adds one rotary; a 5-axis adds two and can tilt the spindle or the table to reach undercuts. Programming rotary axes is not harder in principle — the same G01/G02 rules apply — but the coordinate system rotates, so the tool tip position in space is a function of both linear and rotary position.

Start with 3-axis. Add a C-axis indexing mill (C rotates between moves, not during cutting) before you try true 5-axis simultaneous. Each step adds complexity and a new class of crashes — most often the rotary axis carrying the fixture into the spindle.

Practice

1. Probe left edge at X-25.3, right edge at X24.8. Center?

Ans

(-25.3 + 24.8)/2 = -0.25 mm. Part center is at X-0.25.

2. What is 3+2?

Ans

Rotary axes position at an angle, then XYZ linear milling — no simultaneous rotary motion.

3. Why slow probe feed?

Ans

Probes are delicate. Fast feed bends the stylus and gives false readings.
