Reading and Structuring a CNC Program

A CNC program is not a random list of numbers. This page teaches you the anatomy: program number, blocks, word addresses, and how to read any G-code line.

Concept

A CNC program consists of blocks (lines), each containing words (letter + number). A word like X25.5 means "the X coordinate is 25.5." A block may contain multiple words: G01 X25.5 Y10. F200. means linear motion to (25.5, 10) at 200 mm/min.

Program number (O1001) identifies the program on the controller. Sequence numbers (N10, N20) label blocks for reference but do not affect execution. Comments in parentheses explain what the code does.

Why It Matters

One line is a combination of states and actions. G01 stays active until another motion code replaces it. If you forget that G01 is modal and write X100 without an F, the feed rate from earlier still applies. Reading a program means tracking state, not just reading line by line in isolation.

How It Works

Anatomy of a Block

N10 G01 X100.0 Y50.0 F300.0
  • N10 — sequence number (label only)
  • G01 — linear interpolation (motion mode)
  • X100.0 — X coordinate target
  • Y50.0 — Y coordinate target
  • F300.0 — feed rate

Program Skeleton

  1. Program start (%, O number)
  2. Startup block (G21, G17, G90, G40, G49, G80)
  3. Tool change and spindle start
  4. Positioning and machining
  5. Retract and spindle off
  6. Program end (M30, %)

Example

Starting at (5,10) in G90 G21 G94: G01 X25 Y10 F200 moves 20 mm in X at 200 mm/min. Ideal time = 20/200 = 0.1 min = 6 seconds. This is the steady-state cutting time, not including acceleration/deceleration.

Common Mistakes

  • Treating N numbers as move distances — N10 is a label, not a coordinate.
  • Confusing S and F — S is RPM (spindle speed), F is feed rate.
  • Using M30 as a retract move — M30 ends the program and resets. It does not move axes.

Practice

1. Distance = 30 mm, feed = 300 mm/min. Ideal cutting time?

Show answer

30/300 = 0.1 min = 6 seconds.

2. What does T03 M06 do?

Show answer

Select tool 3 and execute the automatic tool change. The actual tool change sequence depends on the machine.

3. Why is the startup block G21 G17 G90 G40 G49 G80 important?

Show answer

It establishes known machine state: metric units, XY plane, absolute mode, compensation off, cycles off. Without it, leftover modal state from a previous program could cause unexpected motion.
