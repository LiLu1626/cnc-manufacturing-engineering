Anatomy of a CNC Program

Concept

A CNC program is just a text file. Each line (called a block) contains instructions. Each instruction is made of words — a letter plus a number. Once you see the pattern, programs become readable.

Why It Matters

Before you write your own programs, you need to read and understand existing ones. This lesson takes a real program and explains every line so you never feel lost looking at G-code again.

A Real Beginner Program

%                          (1) Program start marker
O1001                     (2) Program number
G21 G17 G90 G40 G49 G80   (3) Safe start block
T01 M06                   (4) Tool change: tool #1
G54                       (5) Use work offset #1
S2000 M03                 (6) Spindle on, 2000 RPM, forward
G00 X0 Y0                 (7) Rapid to part zero in X/Y
G43 H01 Z50. M08          (8) Tool length offset, coolant on
G01 Z-2. F100.            (9) Plunge 2mm deep
G01 X50. Y25. F300.       (10) Cut to position
G00 Z50. M09              (11) Retract, coolant off
M05                       (12) Spindle stop
G91 G28 Z0                (13) Return Z to machine home
M30                       (14) Program end
%

Line-by-Line Explanation

#CodeWhat it doesWhy it's there
1%Tape start/end markerLegacy from punched tape; some controllers require it
2O1001Program numberThe file name the controller stores it under
3G21 G17 G90 G40 G49 G80Safe startSets mm units, XY plane, absolute mode, cancels compensation and cycles
4T01 M06Get tool #1ATC swaps in the tool
5G54Work offsetTells controller where the part is
6S2000 M03Spindle forward 2000 RPMStart cutting speed
7G00 X0 Y0Rapid to part cornerPosition at safe height (Z is still at 50)
8G43 H01 Z50. M08Apply tool length, coolant onZ50 is above the part — safe
9G01 Z-2. F100.Feed down 2mm at 100 mm/minPlunge slowly — never rapid into material
10G01 X50. Y25. F300.Cut at 300 mm/minThis is the actual cutting move
11G00 Z50. M09Rapid up, coolant offGet above the part before moving XY
12M05Spindle stopHousekeeping
13G91 G28 Z0Z to machine homeUsing G91 because G28 goes to reference point
14M30Program end, resetRewinds to start for next cycle

The Building Blocks of a Line

PartExampleMeaning
Sequence numberN10Optional line label (mostly for debugging)
G-wordG01Preparatory function — sets machine mode
Coordinate wordsX100. Y50.Where to go
F-wordF300.Feed rate (mm/min)
S-wordS2000Spindle speed (RPM)
T-wordT01Tool number
M-wordM03Machine function (spindle, coolant, etc.)

Comments go in parentheses: (TOOL 1: 10MM END MILL). They don't affect the machine — they're for humans reading the program. Good programs have comments explaining what each section does.
