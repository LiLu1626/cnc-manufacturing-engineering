Circular & Helical Interpolation

Arcs are programmed with G02 (clockwise) and G03 (counterclockwise). This page covers I/J center vectors, R radius notation, and how to verify arc direction.

Concept

G02 cuts clockwise arcs. G03 cuts counterclockwise. The arc is defined by: start point (current position), end point (X/Y), and either center (I/J) or radius (R). I is the center offset in X from start; J is the center offset in Y from start.

Direction is viewed looking from the positive Z axis down (G17 XY plane). Clockwise = G02, counterclockwise = G03.

Why It Matters

Getting G02/G03 backwards means the tool cuts a bulge instead of a concave — or vice versa. Wrong I/J means the arc center is off, producing a lopsided circle. Always verify: start point, center, end point, direction.

How It Works

I/J Method (center vector)

G17 G02 X50. Y0 I25. J0

Start at (25,0), end at (50,0), center at (50,0). Wait: I25 = center X - start X = 25 - 25 = 0. Let's redo: start at (0,0), center at (25,0), end at (50,0). I = 25 - 0 = 25. J = 0 - 0 = 0. This is a semicircle clockwise from (0,0) to (50,0) through (25,-25) — but wait, G02 clockwise from (0,0) with center (25,0) goes through (25,-25). For the upper semicircle use G03.

R Method (radius)

G17 G03 X50. Y0 R25.

R25 = 25 mm radius. R positive for arcs < 180°; R negative for arcs > 180°.

Example

Full circle: start at (25,0), center at (0,0):

G01 X25. Y0 F300.
G03 I-25. J0  (full circle, ends back at start)

I = center X - start X = 0 - 25 = -25. J = 0. G03 counterclockwise. R cannot do a full circle (start = end); you must use I/J.

Common Mistakes

  • Confusing G02/G03 direction — view from positive Z. CW = G02, CCW = G03.
  • Using R for full circle — R cannot express a 360° circle; use I/J.
  • I/J as absolute center — I/J are offsets from start point, not absolute coordinates.

Practice

1. Start (0,0), center (30,0), end (30,30). G02 or G03?

Ans

From (0,0) to (30,30) around center (30,0): the arc goes up and right — that's clockwise? No. (0,0) is left of center, (30,30) is above center. Moving from left to above = counterclockwise. G03.

2. Start (25,0), center (0,0). What is I?

Ans

I = 0 - 25 = -25.

3. R positive vs negative?

Ans

R+ = arc < 180°. R- = arc > 180°.
