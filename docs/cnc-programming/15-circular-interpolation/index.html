Circular Interpolation — G02 / G03

Concept

To cut an arc, two axes move simultaneously at coordinated speeds. G02 is clockwise, G03 is counterclockwise. You specify: start point (where you are), end point (X/Y destination), and arc center.

The Four Things You Need

Two Ways to Define the Center

MethodSyntaxWhen to use
I / JG02 X__ Y__ I__ J__Precise work. I/J are offset from start to center.
R (radius)G02 X__ Y__ R__Simple arcs. Easier, but can't cut full circles.

Example

Start at X0 Y0, cut a quarter-circle to X20 Y20, center at X0 Y20 (radius 20):

G17 G90 G01 X0 Y0 F300.
G02 X20. Y20. I0 J20.

Why I0 J20? Start is at X0 Y0. Center is at X0 Y20. I = center X − start X = 0. J = center Y − start Y = 20. The tool follows the arc from start to end clockwise.

Common mistake: I/J are incremental from start, not absolute. Beginners write I0 J20 meaning "center at absolute Y20" — which happens to work here, but if the start were at X5 Y5, I would still be 0 and J would still be 20 (the difference), not I5 J25. When unsure, use R.
