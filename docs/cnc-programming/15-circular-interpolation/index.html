Circular & Helical Interpolation

Arcs are programmed with G02 (clockwise) and G03 (counterclockwise). This page covers I/J center vectors, R radius notation, and how to verify arc direction with angles.

Concept

G02 cuts clockwise arcs. G03 cuts counterclockwise. The arc is defined by: start point (current position), end point (X/Y), and either center (I/J) or radius (R). I is the center offset in X from start; J is the center offset in Y from start.

Direction is viewed looking from the positive Z axis down (G17 XY plane). Clockwise = G02, counterclockwise = G03.

Why It Matters

Getting G02/G03 backwards means the tool cuts a bulge instead of a concave — or vice versa. Wrong I/J means the arc center is off, producing a lopsided circle. Always verify: start point, center, end point, direction.

How It Works

I/J Method (center vector)

Start at (0,0), center at (25,0), end at (50,0). I = 25 − 0 = 25. J = 0 − 0 = 0.

From (0,0) to (50,0) around center (25,0): the start vector (−25,0) points west (180°), the end vector (25,0) points east (0°).

  • G02 (clockwise): angle decreases 180° → 90° → 0°, passing through (25, −25) — the lower semicircle. Arc length = π×25 ≈ 78.54 mm.
  • G03 (counterclockwise): angle increases 180° → 270° → 360°/0°, passing through (25, +25) — the upper semicircle. Arc length = π×25 ≈ 78.54 mm.
G17 G02 X50. Y0 I25. J0   (lower semicircle, clockwise)
G17 G03 X50. Y0 I25. J0   (upper semicircle, counterclockwise)

R Method (radius)

G17 G03 X50. Y0 R25.

R25 = 25 mm radius. R positive for arcs < 180°; R negative for arcs > 180°.

Example

Full circle: start at (25,0), center at (0,0). I = 0 − 25 = −25. J = 0. G03 counterclockwise. R cannot do a full circle (start = end); you must use I/J.

G01 X25. Y0 F300.
G03 I-25. J0  (full circle, ends back at start)

Short arc example: start (0,0), center (0,20), end (20,20). Start vector from center = (0,−20) at 270°. End vector = (20,0) at 0°. Going from 270° to 0° counterclockwise (increasing angle) is a 90° short arc = G03, length = π×20×90/360 = 31.416 mm. G02 would take the long 270° way around, length = 94.248 mm.

G17 G03 X20. Y20. I0. J20.   (short 90deg arc, CCW)

Common Mistakes

  • Confusing G02/G03 direction — view from positive Z. CW = G02, CCW = G03. Use angles: if the start-to-end angle decreases, it's G02.
  • Using R for full circle — R cannot express a 360° circle; use I/J.
  • I/J as absolute center — I/J are offsets from the start point, not absolute coordinates.
  • Forgetting to specify short vs long arc — when start and end are exactly opposite, both G02 and G03 can reach the end. Add "short arc" to the drawing note.

Practice

1. Start (0,0), center (30,0), end (30,30). This is a 90° short arc. G02 or G03?

Ans

G02. Start vector from center = (−30,0) at 180°. End vector = (0,30) at 90°. Angle decreases from 180° to 90° = clockwise = G02. Short arc length = π×30×90/360 = 47.124 mm. (G03 would take the 270° long way around, 141.372 mm.)

2. Start (25,0), center (0,0). What is I?

Ans

I = center X − start X = 0 − 25 = −25.

3. R positive vs negative?

Ans

R+ = arc < 180° (short arc). R− = arc > 180° (long arc).
