Subprograms and Repeated Patterns

When a pattern repeats, write it once as a subprogram and call it many times. M98 P calls, M99 returns.

What you will learn:
  • M98 P subprogram call (Haas uses P, not O)
  • M99 return to the main program
  • L repeat count
  • Building hole grids and repeated features

Concept

A subprogram is a separate O-number program called by M98 P and returned by M99. The main program positions the machine; the subprogram performs one repeating unit of work. The L parameter sets the repeat count.

Worked Example

For a 4×3 hole grid, the subprogram drills one row of 4 holes and advances Y. The main program calls it 3 times. See Subprograms — Detailed Example for the full code with the 12-hole trace.

Common Mistakes

  • Using M98 O instead of M98 P on Haas.
  • Adding a redundant first hole that re-drills the current position.
  • Forgetting to reset X or Y after each row.
  • Not cancelling the drill cycle (G80) before moving at height.

Practice

1. On a Haas, how do you call subprogram O2000 three times?

Show answer

M98 P2000 L3. P specifies the program number; L is the repeat count.

2. What does M99 do?

Show answer

Returns from the subprogram to the block after the M98 call in the main program.
