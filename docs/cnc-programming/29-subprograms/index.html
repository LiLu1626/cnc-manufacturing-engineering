Subprograms

Subprograms let you repeat a block of code without copying it. This page covers M98/M99, Haas syntax, and how to use subprograms for hole patterns.

Concept

A subprogram is a separate O-numbered program called from the main program. M98 P2000 L3 calls O2000 three times (Haas syntax). M99 returns to the main program. Subprograms reduce repetition and make programs easier to maintain.

Why It Matters

Without subprograms, drilling 16 holes in a pattern means 16 blocks of G81 code. With a subprogram, you write the hole once and call it 16 times. If the hole depth changes, you edit one line instead of 16.

How It Works

Haas Syntax

M98 P2000 L3   (call O2000, repeat 3 times)

Inside O2000, M99 returns to the line after M98. The subprogram can use incremental (G91) coordinates to move to the next pattern position.

Safe Subprogram Pattern

Before M98, always: (1) retract Z to safe height, (2) declare G90 or G91 explicitly, (3) ensure G80 cancels any active cycle. The subprogram should start from a known position.

Example

4 holes on a 40 mm grid:

(MAIN)
G90 G00 X0 Y0
M98 P2000
X40 Y0
M98 P2000
X40 Y40
M98 P2000
X0 Y40
M98 P2000
G80 Z50.
M30

(SUB O2000)
G91 G81 R2. Z-15. F120.
G80 G00 Z5.
M99

Each call: drill at current XY, retract to R plane, return. The main program positions XY in absolute; the subprogram drills and returns. Note: G80 inside subprogram cancels cycle; explicit G00 Z5. lifts between holes.

Common Mistakes

  • Confusing P and O — Haas uses M98 P2000 (not O2000).
  • Forgetting G80 in subprogram — cycle stays active into the next main program line.
  • Assuming G80 retracts to Z50 — it doesn't. Explicit G00 Z retract needed.

Practice

1. M98 P3000 L5 does what?

Ans

Calls O3000 five times, then returns.

2. Why explicit G00 Z5 after G80?

Ans

G80 cancels cycle mode but leaves Z at the bottom. Explicit retract ensures safe height before the next XY move.

3. Why declare G90/G91 in both main and sub?

Ans

Subprograms inherit modal state. If the subprogram uses G91, the main program must restore G90 after.
