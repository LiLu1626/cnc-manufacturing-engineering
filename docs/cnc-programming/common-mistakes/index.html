04.2 · Common Mistakes

Common Beginner Programming Mistakes

Every new programmer makes these. Knowing them in advance saves you scrap, broken tools, and crashed machines.

MistakeWhat happensHow to avoid
Wrong G54 work offsetMachine cuts in the wrong locationVerify offset before first cut; dry run
Wrong tool length offsetTool plunges too deep or too shallowDouble-check H number matches tool
Forgetting G21/G20Program in mm but machine thinks inch — parts are 25.4x offAlways G21 at program start
Missing G40 / G49 / G80Previous program's mode leaks into new oneSafe-start block at top
G90/G91 confusionCoordinates mean something different than expectedCheck current mode on screen
Rapid into materialZ rapid hits the part at full speedAlways approach Z at feed, not G00
Wrong spindle directionTool cuts backwards, bad finish, broken edgeM03 forward; check rotation
Forgetting M09/M05Coolant floods, spindle spins after endEnd-of-program housekeeping block
G41/G42 without lead-inCutter comp engages mid-cut → crashComp must start on a straight approach move
Copy-pasting code without understandingWorks on one part, fails on nextRead every line you run

The safe-start block is your insurance: G21 G17 G90 G40 G49 G80. Write it at the top of every program. It resets units, plane, coordinate mode, and cancels all compensation. It takes one line and prevents a dozen mistakes.
