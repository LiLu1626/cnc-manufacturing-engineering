How to Use This Glossary

This glossary is a quick reference, not a tutorial. If you read a term and do not understand the full explanation, follow the link to the relevant lesson in this CNC Programming section. Each term is listed in plain English first, then with the controller-specific shorthand where it matters. When two shops use different words for the same thing (for example "work offset" vs "fixture offset" vs "G54"), both are listed so the term from one manual maps to the term from another.

Manufacturers vary: a Haas mill, a FANUC-controlled mill, and a Siemens mill all use the words "G-code" and "work offset," but the exact registers, cycle numbers, and modal groups differ. This glossary uses Haas mill conventions as the baseline and notes where other controllers diverge. If you are running a different controller, treat the term definitions as universal but the specific code numbers as controller-specific.

The Recommended Sources below are the primary manuals and training materials this section draws on. When a term's exact behavior is ambiguous, the manufacturer's manual for your machine model is the final authority — this glossary summarizes, it does not replace the manual.

More Terms

Backlash is the lost motion in a ballscrew when the axis reverses direction. On old knee mills it forces conventional milling; on CNC machines with preloaded ballscrews it is measured in microns. Cutter compensation (G41/G42) offsets the tool center by the D radius so you program the part outline. Datum is the reference feature the drawing dimensions from; set G54 there. Feed per tooth (fz) is the feed advance per flute per revolution (a programmed/allowed value, F / (n×z)); the actual uncut chip thickness depends on radial engagement ae/D and is generally smaller than fz in side milling. G-code is the motion word address language; M-code is the machine function. Nose radius is the radius on a lathe insert tip; it affects shoulder geometry and surface finish. Runout is unwanted spindle or tool wobble; it spreads tool wear and bad finish. Vibratory chatter is self-excited oscillation between tool and part; reduce it by slowing down, shortening tool overhang, or stiffening the setup.

Recommended Sources

  • Haas Automation CNC Programming Manual — free download, covers G/M codes for Haas controls.
  • Society of Manufacturing Engineers (SME) — textbooks on machining fundamentals.
  • Tooling catalogs — Sandvik Coromant, Kennametal, Iscar: cutting speed and feed data.
  • CNC Cookbook (by Peter Smid) — comprehensive G-code reference.
  • Machinery's Handbook — the standard engineering reference shop floor book.

Common Mistakes

  • Confusing similar terms — "feed per tooth" vs "feed per revolution" are different. Use the glossary.

Practice

1. What does G54 do?

Ans

Sets the work coordinate system offset.

2. Modal means?

Ans

The code stays active until another code in the same group replaces it.

3. What is ATC?

Ans

Automatic Tool Changer — the magazine that swaps tools on a mill.
