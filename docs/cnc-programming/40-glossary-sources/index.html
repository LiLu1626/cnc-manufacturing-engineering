Glossary & Sources

Glossary

CAD / CAM
Computer-Aided Design / Manufacturing. The software that generates toolpaths from a 3D model.
Canned Cycle
A pre-programmed subroutine (G81, G83, etc.) that handles positioning, feed, retract in one line.
Coolant Through Spindle (CTS)
High-pressure coolant delivered through the tool holder, improving chip evacuation in deep holes.
Fixture
A workholding device that locates and clamps the part repeatably.
G-Code
Geometry code: commands that control tool motion (rapid, linear, arc, cycles).
Home Position
The machine reference position (machine zero), set during reference return.
MDI
Manual Data Input: typing commands directly on the controller for setup and test moves.
Over-travel
An alarm when an axis moves beyond its physical limit switch.
Post Processor
Software that translates generic CAM toolpath into machine-specific G-code.
Work Offset
The shift between machine zero and work zero (G54–G59).
