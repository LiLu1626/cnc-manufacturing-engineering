Canned Cycles & Hole Patterns

Canned cycles package multi-step motions into one line. This page explains how they work, their modal behavior, and how to drill multiple holes efficiently.

Concept

A canned cycle is a preprogrammed sequence: position, rapid to R, feed to depth, retract. One line replaces 5-6 manual lines. Cycles are modal: once activated, every X/Y move repeats the cycle with the same R, Z, and F until G80 cancels.

Why It Matters

Modal cycles are powerful but dangerous: forget G80 and the next X/Y move becomes a hole. Conversely, understanding modal cycles lets you drill a 20-hole pattern with 20 lines instead of 100.

How It Works

Canned Cycle Structure

  1. Rapid to X/Y position
  2. Rapid to R plane
  3. Feed to Z depth
  4. Retract (G98 to initial Z, G99 to R)

Cancellation

G80 cancels all canned cycles. It must be programmed after the hole pattern before any non-drilling motion. Note: G80 cancels the cycle mode but does NOT retract the tool — if you need to be at a safe Z position, program G00 Z50 explicitly.

Example

4-hole pattern on a 50 mm square, centered at (0,0):

G98 G81 R2. Z-15. F120.
X-25. Y-25.
X25. Y-25.
X25. Y25.
X-25. Y25.
G80 G00 Z50.

Each X/Y line drills one hole. The R, Z, F values are inherited from the cycle. 5 lines (including G81 and G80) for 4 holes.

Common Mistakes

  • Forgetting G80 — cycle continues unexpectedly.
  • Thinking G80 retracts to Z50 — G80 only cancels mode; explicit Z retract needed.
  • Changing R/Z between holes without re-commanding — R and Z are modal; re-specify only when they change.

Practice

1. After G81, you write X10 Y20. What happens?

Ans

Drills at (10,20) with the same R, Z, F as G81.

2. Why program G00 Z50 after G80?

Ans

G80 cancels cycle mode but leaves the tool at whatever Z it was at. Explicit retract ensures safe Z before tool change or XY move.

3. 8 holes on bolt circle, same depth. How many G81 lines?

Ans

One G81 line + 8 X/Y position lines + G80.
