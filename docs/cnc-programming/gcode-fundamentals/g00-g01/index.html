02.1 · G00 / G01

G00 Rapid and G01 Linear Feed

G00 and G01 are the two most used motion codes. G00 moves fast (no cutting). G01 moves at a controlled feed (cutting). Master these and you can write half of any program.

G00 — Rapid Positioning

Moves the tool as fast as possible to a position. No cutting happens in G00. Use it to approach the part, retract, and move between cuts.

G00 can move multiple axes at once — diagonally. This means the tool might crash into the part or fixture on the way. Always approach in Z first (at a safe XY position), never rapid into the cut.

G01 — Linear Interpolation

Moves the tool in a straight line at the programmed feed rate F. This is cutting motion.

Example Program

G90 G54 G00 X0 Y0        (RAPID to part corner, safe Z)
G43 H01 Z50. M08         (tool length offset, coolant on)
G01 Z-2. F100.           (PLUNGE down 2mm at 100 mm/min)
G01 X100. F300.          (CUT along X to 100mm at 300 mm/min)
G00 Z50. M09             (RETRACT fast, coolant off)
G91 G28 Z0               (Z to home)
M30

Key Rules

RuleWhy
G00 = no cut, fastNever rapid into material
G01 = cut, needs F wordFeed is modal — set once, it persists
Approach in Z first, then X/YAvoid diagonal rapid crashes
Retract in Z before moving XYDon't drag the tool on the part

Modal warning: G01 stays active until G00 or another motion code replaces it. Once you write G01 X100 F300, the next line X150 is still G01 at F300. You don't repeat G01 and F every line — but you must know they're still active.
