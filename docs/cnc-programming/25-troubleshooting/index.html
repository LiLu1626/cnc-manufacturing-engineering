Program Troubleshooting

Concept

When the machine alarms or moves wrong, work backwards: what did the code tell it to do, what did the offsets say, and what mode was it in? Most problems are not mysterious — they're offset errors, wrong mode, or a missing G-code.

SymptomLikely causeCheck
Alarm on startSyntax error, missing M03, tool not foundRead alarm message, check first lines
Tool moves wrong directionG90 vs G91, or wrong axis directionCheck current mode on screen
Cuts in wrong locationWrong G54 offset, or wrong corner touched offVerify G54 values, dry run
Z cuts too deepWrong H offset, or G49 not canceledCheck tool length offset H number
Arc error alarmI/J wrong, or radius too small for start/endRecalculate center offset
Unexpected hole cycleG80 missing after drillingLook for G80 line
Dimensions 25.4× offG20/G21 mismatchConfirm units at program start
Feed too fast/slowG94 vs G95 mode wrongCheck feed mode on screen

Diagnose before you change the code. Read the alarm number, look at what line the machine stopped on, and check the modal state (G90/G91, G20/G21, G41/G42). 80% of the time, the problem is a missing or wrong G-code — not a mysterious machine fault.
