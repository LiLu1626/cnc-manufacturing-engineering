Go from never having seen G-code to reading, writing, and checking basic mill and lathe programs. Built for machinists, operators, and engineers who want to understand — not just copy.

Start with What Is CNC Programming → View the Learning Path →

Before You Start

No prior programming experience required. You only need basic arithmetic and a willingness to draw coordinates on paper. Examples use metric units on a 3-axis vertical mill and a 2-axis lathe, with Haas-verified G-code syntax as the reference dialect. This course teaches manual programming concepts; it does not certify you to operate a real machine without hands-on training.
