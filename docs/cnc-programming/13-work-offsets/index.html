Work Offsets & Datums

G54 tells the machine where the part is. This page explains work coordinate systems, datum selection, multiple work offsets, and the critical formula: machine zero + work offset + tool offset = actual tool position.

Concept

A work offset (also called fixture offset or work coordinate system) shifts the coordinate system from machine zero to a chosen point on the part. G54 is the default work offset. G55 through G59 provide additional work coordinate systems for multiple parts, multiple setups, or multiple datums.

The machine always operates in machine coordinates. The G54 offset tells the controller: "the part origin is at this machine position." When you program X0 Y0, the machine goes to the G54 origin in work coordinates, which is a specific machine position.

Why It Matters

If G54 is set 2 mm off in X, every feature on the part shifts 2 mm. This is the most common cause of scrap parts: the program is correct, but the setup offset is wrong. Work offsets let you run the same program on multiple setups without changing code — just enter a different G55, G56, etc.

How It Works

The Offset Chain

Machine position = Machine zero + Work offset + Tool offset

Three independent systems combine:

  1. Machine zero — fixed, established on homing
  2. Work offset (G54) — where the part origin is, set during setup
  3. Tool offset (H/D) — where the tool tip is relative to spindle

Setting G54

On a mill, you touch off: move the tool to the part edge, measure, and enter the result. On a lathe, you touch the face (Z0) and OD (X diameter). The controller calculates the offset automatically.

Multiple Work Offsets

Run two identical parts on a tombstone: G54 for part 1, G55 for part 2. The same program runs without modification — just switch G54 to G55.

Example

Machine zero is at X0 Y0 (home position). You set G54 so the part corner is at machine position X350 Y200. When the program says G00 X0 Y0, the machine goes to machine (350, 200). When it says X10 Y10, the machine goes to (360, 210).

You have two parts on the table: part 1 at machine (350, 200), part 2 at machine (450, 200). Set G54 = (350, 200) and G55 = (450, 200). The program G54 X0 Y0 goes to part 1; G55 X0 Y0 goes to part 2.

Common Mistakes

  • Setting G54 on the wrong edge — touching the left edge vs right edge changes the X offset by the part width.
  • Using G54 for tool length — G54 is work offset (X/Y/Z position); tool length is G43 H offset. They are separate.
  • Running G55 setup with G54 active — verify which offset is active before cutting.

Practice

1. Machine zero is at X0. G54 X offset = 350. Program X20. What machine position?

Show answer

350 + 20 = X370.

2. Why use G55 instead of manually moving the stock?

Show answer

G55 lets you run the same program on a second part without modifying code. The program stays identical; only the offset changes.

3. You touch off the wrong side (left instead of right) on a 60 mm part. What is the error?

Show answer

The X offset is off by 60 mm — the part origin is at the wrong corner. Every X coordinate is shifted by 60 mm.
