Work Offsets (G54–G59)

Concept

The work offset tells the controller where your part sits on the machine table. It's the difference between machine zero and your chosen part zero. You set it during setup by touching off.

The Core CNC Equation

Machine Zero + Work Offset (G54) + Tool Offset = Actual Tool–Workpiece Position

This is the single most important equation in CNC programming. Every coordinate you write is measured from work zero. The controller figures out where that is in machine space by adding the offset.

Multiple Work Offsets

OffsetTypical use
G54Primary part / first setup
G55Second part on the same table (second vise)
G56, G57Additional parts / fixtures
G58, G59Pallet positions or special setups

Example: Two identical parts side by side

You clamp two vises 200 mm apart on the table. You set G54 for vise 1 and G55 for vise 2. The program runs:

G54 ... (cut part in vise 1)
G55 ... (cut part in vise 2, same program)

You don't rewrite coordinates — you just switch the offset. This is how you run multiple parts per setup.

Wrong G54 is the #1 crash cause. If you set the offset on the wrong corner, or forget to update it after moving the part, the machine cuts exactly where you tell it — which is the wrong location. Always verify with a dry run or single-block the first cut.
