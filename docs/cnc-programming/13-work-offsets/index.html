Work Offsets & Datums

G54 tells the machine where the part is. This page explains work coordinate systems, datum selection, multiple work offsets, and the critical formula that combines machine zero, work offset, and tool offset into the actual tool position.

Concept

A work offset (also called fixture offset or work coordinate system) shifts the coordinate system from machine zero to a chosen point on the part. G54 is the default work offset. G55 through G59 provide additional work coordinate systems for multiple parts, multiple setups, or multiple datums on the same part.

The machine always operates in machine coordinates internally. The G54 offset tells the controller: "the part origin is at this machine position." When you program X0 Y0, the machine goes to the G54 origin in work coordinates, which maps to a specific machine position.

Why It Matters

If G54 is set 2 mm off in X, every feature on the part shifts 2 mm. This is the most common cause of scrap parts: the program is correct, but the setup offset is wrong. Work offsets also let you run the same program on multiple setups without changing code — just enter a different G55, G56, etc.

The Offset Chain

Machine position = Machine zero + Work offset (G54) + Tool offset (H)

Three independent systems combine to place the tool tip exactly where you want it:

  1. Machine zero — fixed, established on homing. Never changes.
  2. Work offset (G54) — where the part origin is, set during setup by touching off.
  3. Tool offset (H) — where the tool tip is relative to the spindle face, set during tool measurement.

If any one of these three is wrong, the tool tip lands in the wrong place. This is why verifying all three before the first cut is essential.

Setting G54 on a Mill

  1. Mount an edge finder or dial indicator in the spindle.
  2. Jog the tool to touch the left edge of the part. Set G54 X = that machine position + tool radius (edge finder center).
  3. Repeat for the right edge to verify, or touch the known corner.
  4. Touch the top surface for Z0. Set G54 Z = that machine position.
  5. Verify by moving to X0 Y0 and checking the tool is at the part corner.

Multiple Work Offsets

Run two identical parts on a tombstone or fixture plate: G54 for part 1, G55 for part 2. The same program runs without modification — just switch G54 to G55 in the program. This is how production machines handle multiple parts per setup.

CodeTypical Use
G54Primary fixture / part 1
G55Part 2 on same tombstone
G56Part 3 / second operation
G57–G59Additional datums or fixtures

Example

Machine zero is at the home position. You set G54 so the part corner is at machine position X350 Y200. When the program says G00 X0 Y0, the machine goes to machine (350, 200). When it says X10 Y10, the machine goes to (360, 210).

Two parts on the table: part 1 at machine (350, 200), part 2 at machine (450, 200). Set G54 = (350, 200) and G55 = (450, 200). The program G54 X0 Y0 goes to part 1; G55 X0 Y0 goes to part 2.

Common Mistakes

  • Setting G54 on the wrong edge — touching left vs right changes X offset by the part width. Verify the corner.
  • Using G54 for tool length — G54 is work offset (X/Y/Z part position); tool length is G43 H offset. They are separate tables.
  • Running G55 setup with G54 active — always verify which offset is active before cutting.
  • Forgetting to reset G54 after a fixture change — if the fixture moved, G54 must be re-established.
  • Probing and entering raw machine coordinates as G54 — the probe result needs to be transformed: if you probe the left edge, G54 X = probe position + tool radius, not the raw probe coordinate.

Practice

1. Machine zero is at X0. G54 X offset = 350. Program X20. What machine position?

Show answer

350 + 20 = X370.

2. Why use G55 instead of manually moving the stock?

Show answer

G55 lets you run the same program on a second part without modifying code. The program stays identical; only the offset changes. This is essential for tombstone production.

3. You touch off the wrong side (left instead of right) on a 60 mm part. What is the error?

Show answer

The X offset is off by 60 mm — the part origin is at the wrong corner. Every X coordinate shifts by 60 mm.

4. What is the difference between G54 and H01?

Show answer

G54 is the work offset (where the part origin is in machine coordinates). H01 is the tool length offset (where the tool tip is relative to the spindle). They are independent tables that combine to position the tool tip correctly.
