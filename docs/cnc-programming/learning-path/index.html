Learning Path

CNC Programming Learning Path

Follow these steps in order. Each lesson builds on the previous. Don't skip ahead — coordinates and offsets are the foundation everything else stands on.

Level 1 — Foundations

#LessonYou'll be able to...
1What Is CNC Programming?Explain how code becomes machine motion
2Coordinate SystemsUnderstand machine zero, work zero, G54, G90/G91
3Program StructureRead and explain every line of a basic program

Level 2 — Motion Codes

#LessonYou'll be able to...
4G00 / G01Write straight-line cutting motion safely
5G02 / G03Program arcs and circles
6M-CodesControl spindle, coolant, tool change, stop/end

Level 3 — Offsets & Cycles

#LessonYou'll be able to...
7Work OffsetsSet up G54 and run multiple setups
8Tool OffsetsUse length and radius compensation
9Canned CyclesDrill hole patterns efficiently

Level 4 — Professional Practice

#LessonYou'll be able to...
10Program VerificationProve a program is safe before cutting
11Common MistakesRecognize and avoid classic errors

Next up: Turning and milling complete programs, threading, subprograms, and controller-specific details. After these fundamentals, you'll be ready to read, write, and check real shop programs.
