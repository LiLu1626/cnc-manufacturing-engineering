02.3 · M-Code Fundamentals

M-Codes — Machine Functions

If G-codes control motion, M-codes control everything else: spindle on/off, coolant, tool change, program stop. They're "miscellaneous" but essential.

Common M-Codes

CodeFunctionWhen it runs
M03Spindle forward (clockwise)Start of cut
M04Spindle reverseRarely used
M05Spindle stopEnd of cut
M06Tool changeCall T-code first
M08Coolant onBefore cutting
M09Coolant offAfter cutting
M00Program stop (unconditional)Press cycle start to continue
M01Optional stop (operator switch)For inspection during setup
M30Program end, reset to startEnd of every program

M-codes can be machine-specific. The list above is standard Fanuc-compatible. On some machines, M-codes for chuck clamp, tailstock, or pallet change differ. Always check your machine's manual for non-obvious M-codes.

Typical Program Flow

T01 M06          (1. Change tool)
G54 S2000 M03    (2. Work offset, spindle on)
G00 X0 Y0        (3. Position)
G43 H01 Z50. M08 (4. Tool offset, coolant on)
... CUT ...
G00 Z50. M09     (5. Retract, coolant off)
M05              (6. Spindle stop)
G91 G28 Z0       (7. Z home)
M30              (8. End program)

Never forget M09 and M05. Leaving coolant on after the program ends floods the machine. Leaving the spindle spinning after M30 is wasteful and dangerous. The end-of-program block should always include them.
