Program Safety & Startup Blocks

Concept

Every program should start by putting the machine in a known, safe state. This is the "safe start" block: G21 G17 G90 G40 G49 G80. Don't just copy it — understand what each word does.

The Safe-Start Block Explained

CodeWhat it resetsWhy it matters
G21Units = mmPrevents inch/mm mismatch
G17Plane = XYCorrect plane for arcs
G90Absolute modeCoordinates measured from work zero
G40Cancel cutter compNo unexpected radius offset
G49Cancel length offsetNo unexpected Z offset
G80Cancel canned cycleNo leftover drilling cycle

Why this matters: The previous program may have ended with cutter compensation active, in G91 incremental mode, or in G20 inches. If you don't reset, your new program runs in the wrong state. The safe-start block costs one line and prevents a dozen crashes.

Safe End-of-Program

G00 Z50. M09    (retract, coolant off)
M05             (spindle stop)
G91 G28 Z0      (Z to machine home)
M30             (program end, reset)
