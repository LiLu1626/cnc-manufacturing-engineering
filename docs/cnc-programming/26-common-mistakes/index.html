Common Beginner Programming Mistakes

Every new programmer makes these. Knowing them in advance saves you scrap, broken tools, and crashed machines.

MistakeWhat happensHow to avoid
Wrong G54 work offsetMachine cuts in the wrong locationVerify offset; dry run first
Wrong tool length offset (H)Tool plunges too deep or shallowDouble-check H matches tool
Missing G21mm vs inch mismatch — parts 25.4× offAlways G21 at program start
Missing G40/G49/G80Previous program's mode leaks inSafe-start block at top
G90/G91 confusionCoordinates mean wrong thingCheck mode on controller screen
Rapid (G00) into materialZ crashes into part at full speedAlways G01 for plunge moves
Wrong spindle directionBad finish, broken edgeM03 forward; verify rotation
Forgetting M09/M05Coolant floods, spindle keeps spinningEnd-of-program housekeeping
G41/G42 without lead-inTool jumps sideways mid-cut → crashComp must start on straight approach
Missing G80 after drillingEvery move becomes a holeWrite G80 when done drilling
Wrong arc center (I/J)Arc error alarm or wrong cutI/J is offset from start, not absolute
Copy-pasting code without understandingWorks on one part, fails on nextRead every line you run

The safe-start block is your insurance: G21 G17 G90 G40 G49 G80. One line, six mistakes prevented. Write it at the top of every program, every time.
