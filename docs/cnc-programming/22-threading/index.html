Threading Overview

Single-point threading cuts a helical thread by synchronizing spindle rotation with tool feed. The feed per revolution must equal the thread pitch.

What you will learn:
  • Pitch vs lead, major vs minor diameter
  • Why threading requires G97 (constant RPM)
  • Multiple passes with decreasing depth
  • Lead-in and lead-out distances

Thread Terminology

Pitch = distance between adjacent threads (mm). Lead = distance the tool advances in one spindle revolution (pitch for single-start threads). Major diameter = outer diameter. Minor diameter = root diameter.

Why Constant RPM

The tool feed in mm/rev must equal the pitch. If spindle speed varies (G96), the lead changes and the thread is ruined. Threading always uses G97 fixed RPM.

Multiple Passes

A thread cannot be cut in one pass. The cycle takes successive radial cuts with decreasing depth, using the full thread depth K and first-pass depth D. See Lathe Threading Cycles for the G76 parameter details.

Common Mistakes

  • Confusing pitch (mm/rev) with feed rate (mm/min).
  • Not leaving lead-in distance — the spindle needs to sync before the thread starts.
  • Cutting the full depth in one pass — tool breaks.

Practice

1. M10×1.5: what is the feed in mm/rev?

Show answer

F1.5 mm/rev (the pitch, for single-start).

2. Why must threading use G97?

Show answer

The feed per revolution must equal pitch. G97 keeps RPM constant; G96 would vary it and ruin the thread form.
