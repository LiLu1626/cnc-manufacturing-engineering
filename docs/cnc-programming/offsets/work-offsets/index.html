03.1 · Work Offsets

Work Offsets — G54 to G59

The work offset tells the controller where your part is sitting on the machine. Without it, the machine has no idea where to cut. This is one of the most important setup concepts.

The Core Formula

Actual tool position = Machine position + Work offset (G54) + Tool offset

You set G54 by touching off: the tool touches the corner of the part, you press "set", and the controller records the difference between machine zero and that corner. From then on, every X/Y/Z in your program is measured from that corner.

When to Use G55, G56, ...

OffsetUse for
G54Primary part / setup
G55Second part on the same table (e.g. two vises)
G56Third part or a different fixture
G57–G59Additional setups / pallets

Example: Two vises on one table

You set up two identical vises on the mill table, 200 mm apart. You set G54 for vise 1 and G55 for vise 2. The same program runs: when it says G54, it cuts part 1; when it says G55, it cuts part 2. You don't rewrite the program for each part — you just change the offset.

Wrong G54 is the #1 crash cause. If you set G54 on the wrong corner, or forget to update it after moving the part, the machine will cut exactly where you tell it — which is the wrong place. Always verify G54 with a dry run or single-block before cutting.
