03.2 · Tool Offsets

Tool Offsets

The machine knows where the spindle nose is. It doesn't know how long your tool is, or how wide. Tool offsets teach the controller each tool's geometry so the tip ends up where the program expects.

Tool Length Offset (Milling)

Every tool in the magazine has a different length. When you call T01, the machine moves Z to the same spindle position — but the tool tip is at a different Z for each tool. G43 H01 tells the controller: "apply tool #1's length offset."

CodeMeaning
G43 H01Apply tool length offset from register H01
G49Cancel tool length offset

Tool Radius / Cutter Compensation

When milling a contour, you program the part outline — not the tool center path. The controller uses cutter compensation to offset the tool center by the tool radius.

CodeMeaning
G41Cutter left compensation (tool left of programmed path)
G42Cutter right compensation
G40Cancel cutter compensation

Why offsets matter: They let you program the part dimensions directly. You don't recalculate tool center paths by hand. If the tool is 0.5 mm smaller than nominal, you just update the offset — no program change. This is why modern machining is flexible.

Always cancel compensation at the end of the program (G40, G49). If you leave compensation active, the next program starts in the wrong state. The safe-start block (G40 G49) prevents this.
