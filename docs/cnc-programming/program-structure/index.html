01.3 · Program Structure

Anatomy of a CNC Program

A real CNC program looks cryptic at first. Once you break it down line by line, every line has a job. Here's a typical milling program, explained.

A Complete Beginner Program

%
O1001
G21 G17 G90 G40 G49 G80     (SAFE START)
T01 M06                       (CALL 10MM END MILL)
G54                           (WORK OFFSET)
S2000 M03                     (SPINDLE ON, 2000 RPM)
G00 X0 Y0                     (RAPID TO PART ZERO)
G43 H01 Z50. M08             (TOOL LENGTH OFFSET, COOLANT ON)
G01 Z-2. F100.               (PLUNGE 2MM DEEP)
G01 X50. Y25. F300.          (CUT TO POSITION)
G00 Z50. M09                  (RETRACT, COOLANT OFF)
G91 G28 Z0                    (RETURN TO Z HOME)
M30                           (PROGRAM END)
%

Line-by-Line Breakdown

LineWhat it does
%Program start/end marker (tape symbol)
O1001Program number — the machine stores this file as O1001
G21Units = millimeters (G20 = inches)
G17Plane = XY (for circular interpolation)
G90Absolute coordinates
G40Cancel cutter compensation
G49Cancel tool length offset
G80Cancel any canned cycle
T01 M06Get tool #1 from magazine
G54Use work offset #1
S2000 M03Spindle forward at 2000 RPM
G43 H01 Z50.Apply tool length offset H01, go to Z50 (safe height)
M08Coolant on
M30Program end and reset to start

The Building Blocks

Every G-code line is made of words like G01 X100.0 F300.. Each word is a letter (address) plus a number. A group of words on one line is a block. Blocks run one after another.

The "safe start" block matters. G21 G17 G90 G40 G49 G80 sets the machine to a known, safe state. If you skip this, the machine might be in inch mode, in cutter compensation, or in a canned cycle from the last program — and your coordinates will be wrong. Every program should start this way.
