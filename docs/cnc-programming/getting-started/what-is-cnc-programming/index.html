What Is CNC Programming?

CNC programming is writing the instructions that tell a CNC machine how to make a part. The machine reads your code, moves the axes, spins the spindle, and cuts — all automatically. This page builds the big picture before you see a single G-code.

The Big Picture

What Does a CNC Program Actually Control?

It tells the machine...Example
Where to move (axes)Go to X50, Y20
How fast to move (feed)Move at 300 mm/min
How fast the spindle spinsSpindle at 2000 RPM
Which tool to useCall tool number 3
When to turn coolant on/offM08 / M09
When to stopM30 (program end)

Manual Programming vs CAM

Manual ProgrammingCAM Programming
HowYou write G-code by hand (or on the controller)Software generates G-code from a 3D model
Best forSimple parts, turning, holes, basic contoursComplex 3D surfaces, molds, pockets
Skill neededUnderstand coordinates, G-code, offsetsCAD/CAM software + understanding the generated code
You still need to know...Coordinates, offsets, safety, verification — whether you write it by hand or CAM does.

Even if you use CAM, you must understand G-code. CAM generates code, but you're responsible for checking it: correct offsets? safe rapids? proper feeds? A CAM post-processor can output garbage, and you need to recognize it. This course teaches you to read and verify any program.

NC vs CNC — Minor Distinction

NC (Numerical Control) is the older term; CNC (Computer Numerical Control) is modern. They mean the same thing today — a computer controls the machine axes. You'll see both terms used interchangeably.
